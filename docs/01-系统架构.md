# 系统架构

## 1. 项目边界

项目由共享 DXF 语义但运行时独立的两部分组成：

| 部分       | 入口                              | 输出                     | 是否依赖 SAM                    |
| ---------- | --------------------------------- | ------------------------ | ------------------------------- |
| SAM 插件   | Qt 对话框或`Example1.importDxf` | Sketch 或 FE Part        | 是                              |
| Web Studio | `page/index.html`               | 浏览器工作副本或点线 DXF | 否                              |
| 图形 Agent | `/api/agent/process`            | 待用户确认的点线工作副本 | 否，依赖本地 Node 服务和 AI API |

Web 解析器与 C++ 解析器不是同一个实现，因此通过共同样例、坐标级测试和几何指纹防止语义漂移。

## 2. SAM 插件分层

```text
Example1Toolset.cpp (Qt GUI)
    │  omuMethodCall("Example1", "importDxf", args)
    ▼
Example1Module.cpp (Python/SAM 适配)
    ▼
DxfImportApplication.cpp (公共用例编排和唯一模式分叉)
    ├─ DxfData（请求、结果、校验和公共 DXF 数据）
    ├─ DxfParser ── libdxfrw
    ├─ SketchConversion ── SamData ── SketchImport
    └─ FeConversion ───── FeData  ── FeImport
```

主要职责：

| 模块                      | 职责                                                |
| ------------------------- | --------------------------------------------------- |
| `DxfInputFile`          | 为 libdxfrw 适配 Unicode 路径并管理临时副本         |
| `DxfParser`             | 接收 libdxfrw 回调，校验实体并执行坐标变换          |
| `DxfBlockExpansion`     | 展开块、组合仿射变换、继承图层、执行预算            |
| `DxfData`               | 保存解析后的带类型几何和实体统计                    |
| `GeometryUtils`         | 圆弧、多段线凸度、椭圆和样条离散                    |
| `SketchConversion`      | 生成 Sketch 使用的 `SamData` 和 Sketch 事务顺序    |
| `FeConversion`          | 生成 FE 节点和 Truss，并定义 FE 事务顺序            |
| `SketchImport`          | 使用 SAM C++ SDK 创建并提交 Sketch                 |
| `FeImport`              | 使用 SAM Python API 创建 Model/Part/Node/Truss     |
| `DxfImportRuntime`      | 每次导入的日志、事务状态和生命周期收口             |

## 3. CMake 目标

`3rdParty/` 预留给实际第三方库内容。根 `CMakeLists.txt` 把它加入依赖搜索路径，并在
对应子目录存在时优先使用本地 SAM/SAMSDK、libdxfrw、spdlog 和 OCCT；不存在时才回退
到开发环境原路径。

```text
3rdParty/<依赖名>/         实际第三方库（可选的项目本地副本）
            │ 根 CMake 解析路径
            ▼
ExampleProjectOptions
 ├─ Example1Core            公共 DXF 数据、几何、日志和事务
 ├─ Example1SketchCore      Sketch 数据与纯转换
 ├─ Example1FeCore          FE 数据与纯转换
 ├─ Example1DxfInput        Unicode 文件输入适配
 └─ Example1DxfParser       解析与 BLOCK/INSERT，依赖 libdxfrw

Example1                    SAM Python 扩展，输出 Example1.pyd
Example1Toolset             Qt 插件，输出 SAM.Pre.Example1Toolset.dll
```

测试链接生产静态库，不重复编译生产 `.cpp`。

## 4. Web 分层

浏览器端：

| 文件                                            | 职责                                           |
| ----------------------------------------------- | ---------------------------------------------- |
| `dxf.js`                                      | ASCII DXF 解析、BLOCK 展开、曲线离散和点线导出 |
| `state.js`                                    | 应用状态、快照和基础工具                       |
| `viewport.js` / `renderer.js`               | 视口变换和 Canvas 绘制                         |
| `selection.js`                                | 点击、框选和拖动选择                           |
| `import-controller.js`                        | 文件导入、重离散和导出                         |
| `editor-controller.js`                        | 编辑命令、快捷键和事件编排                     |
| `ui-controller.js`                            | 图层/实体列表、属性面板和刷新                  |
| `agent-settings.js` / `agent-controller.js` | Agent 配置、安全会话、预览与应用               |
| `app.js`                                      | 启动顺序和组合根                               |

服务端：

| 文件                              | 职责                               |
| --------------------------------- | ---------------------------------- |
| `server.js`                     | 监听和公共导出                     |
| `server/router.js`              | 路由与错误响应                     |
| `server/security.js`            | Origin、CORS 和 CSRF 校验          |
| `server/http-utils.js`          | 有界 JSON 请求体                   |
| `server/static-server.js`       | 静态页面和目录穿越保护             |

| `provider-request.js`           | 超时、响应上限、凭据头和禁止重定向 |
| `server/geometry-tools.js`      | 受约束的点线检查与编辑工具         |

## 5. 数据所有权

- `DxfData` 属于解析阶段；转换完成后可以尽早清空以释放大图内存。
- `SamData`、`FeData` 属于一次导入，只有构建服务提交成功后才算发布。
- Builder 拥有尚未提交的 SAM 对象，失败或取消必须回滚。
- Web Agent 操作深拷贝后的工作副本，用户点击“应用”前不改变页面当前几何。
- 浏览器保留原始导入基线，用于恢复和重新离散。

## 6. 仓库边界

活动 C++ 实现只位于 `src/Example1/` 和 `src/Example1Toolset/`。历史教学源码快照已经
从当前树移除，需要追溯时使用 Git 历史。`.codex-worktrees/`、`build*`、`bin/`、`lib/`
和 `tmp/` 都是本地工作产物，不属于发布源码。
