# 当前状态与主要变更

## 1. 当前结论

当前生产基线通过最终复审，自动化和既有 SAM GUI 验收没有发布阻断项。阶段五性能优化按
用户决定跳过，因此本文只陈述已经验证的正确性、稳定性和无回退结果，不声明新的性能收益。

## 2. 已完成能力

### DXF 正确性

- BLOCK/INSERT 使用完整仿射矩阵，覆盖嵌套、阵列、镜像和非均匀缩放；
- 块内圆弧、椭圆、多段线和样条正确处理角度、方向、主轴、切向量和 Z；
- layer 0 继承 INSERT 图层，显式子图层保持自身语义；
- 数值边界拒绝 NaN/Inf 和无效实体；
- Unicode、空格和扩展字符路径由统一输入适配处理。

### 资源与数据完整性

- C++ 和 Web 都有 INSERT 实例、深度和最终输出预算；
- 超限不会继续返回可提交的部分几何；
- Sketch/FE 共享结构化结果和事务状态机；
- 失败、取消和 commit 失败执行补偿清理；
- rollback 失败保留原始错误并允许重试；
- FE 节点使用空间索引合并，Truss 使用无向索引去重。

### 结构

- Parser、BLOCK 展开、输入路径适配和转换核心已拆分；
- Python 绑定只负责参数适配和结果转换；
- Web 页面按状态、视口、绘制、选择、导入、Agent、UI 和编辑器分模块；
- Server 按路由、安全、静态资源、提供商和几何工具分模块；
- CMake 使用明确源列表和稳定目标，测试链接生产实现。

### 安全

- Agent API Key 不写入 `localStorage`；
- Origin、JSON Content-Type 和 CSRF Token 共同保护 Agent POST；
- 服务端密钥固定到服务端端点，自定义端点必须使用请求级密钥；
- 上游禁止重定向，并限制总超时和响应体；
- HTTP 请求体和点线数量有硬上限。

- 日志查看器停止、切换、关闭和重开正常；
- 所有用例后既有 SAM Repository 对象仍存在。

## 5. 已知边界

- C++/Web 只转换项目支持的几何实体；文字、填充和部分注释不进入最终点线/Sketch/FE；
- Web 只读取 ASCII DXF，不直接读取 DWG 或二进制 DXF；
- Web 导出只保留离散后的 POINT/LINE 和图层，不恢复原曲线/BLOCK；
- Unlimited 仍可能消耗大量时间和内存，只适用于受信任输入；
- SAM SDK、Qt 5.12.6 和 Python 2.7 是平台约束；
- Qtitan/Python 2.7 第三方头文件仍有既有编译警告；
- `ContainerShipSection*` 默认关闭，未纳入当前活动模块验收；

## 6. 后续工作

如重新启动性能阶段，应先在真实 SAM GUI 中记录解析、转换、创建、总耗时和峰值内存，
只优化数据证明的热点，并保持几何指纹和事务语义不变。其他独立事项包括：

- SAM/Qt/Python SDK 升级与第三方警告隔离；
- `ContainerShipSection*` 独立审查；

历史阶段方案、逐批实施报告和旧审查记录已经从当前文档集移除，需要追溯时使用 Git 历史。
