## 一、架构概览

```
                      ┌──────────────────────────┐
                      │   Example1PytModule       │  Python 入口 + 管道编排
                      │   importDxf()             │
                      └─────┬──────┬──────┬───────┘
                            │      │      │
                 ┌──────────┘      │      └──────────────┐
                 ▼                 ▼                     ▼
          DxfParser           ConversionEngine       SamBuilder
          parseFile()         convert()              beginImport()
              │                   │                  create*()
              ▼                   ▼                  commit()
          DxfData              SamData
              │                   ▲
              │       ┌───────────┘
              ▼       │
         GeometryUtils │
         tessellate*() │  ← Arc/Ellipse/LWPolyline/Spline
                       │
              ┌────────┴────────┐
              │  DxfImportLogger │  日志 + failImport
              └─────────────────┘
```

**数据流**: `.dxf` 文件 → `DxfParser` → `DxfData`（原生几何）→ `ConversionEngine`（离散化+平移+过滤）→ `SamData` → `SamBuilder`（SAM SDK 草图）→ 提交数据库 → 场景展示

**Spline 离散化内部结构：**
```
tessellateSpline(DxfSpline, tolerance) → vector<DxfLine>
  ├─ buildCurveFromControlData()    // 控制点 + 节点向量 → OCCT B-spline
  ├─ buildCurveFromFitPoints()      // 拟合点 → GeomAPI_Interpolate 插值
  ├─ discretizeByDeflection()       // OCCT 曲线 → GCPnts_TangentialDeflection → 采样点
  └─ 闭合性检查 + 端点 snap
```
