# 船舶 CAD 图纸导入 SAM 插件需求分析报告

## 1\. 引言

### 1\.1 编写目的

本文档用于明确船舶 CAD 图纸导入 SAM 插件的业务目标、功能需求、非功能需求、约束条件及验收标准，作为后续系统设计、开发实现、测试和项目验收的依据。

### 1\.2 项目背景

进行 CAE 仿真的工程师通常已经拥有 CAD 图纸。为了在 SAM 软件中继续进行建模与仿真，工程师需要将 CAD 图纸中的几何内容转换为 SAM 可识别的点、线及多段线。若完全依赖人工重建，不仅工作量较大，而且容易出现坐标偏移、图元遗漏和精度不一致等问题。

因此，本项目拟在 SAM 软件中提供一个带有图形化操作界面的插件。插件读取 DXF 文件，解析其中的几何图元，将不能被 SAM 直接使用的曲线近似拟合为多段线，并在 SAM 中生成相应的点和线。

### 1\.3 适用范围

本文档适用于以下人员：

- 项目负责人和需求提出方；

- 系统设计与开发人员；

- 测试与验收人员；

- 使用插件进行 CAD 图纸导入的 CAE 工程师。

## 2\. 总体描述

### 2\.1 用户角色

本系统的主要使用角色为进行 CAE 仿真的工程师。该类用户已经拥有 CAD 图纸，希望将图纸中的几何内容快速、准确地导入 SAM，以便在 SAM 中继续开展建模或仿真工作。

### 2\.2 核心诉求

系统应将现有 CAD 图纸以 DXF 文件形式导入 SAM，自动解析文件中的几何图元，并在 SAM 中生成对应的点、线和多段线，减少人工重建图纸的工作量。

### 2\.3 系统目标

1. 支持 DXF 文件的选择、读取和解析。

2. 将解析后的 DXF 几何数据转换为 SAM 可使用的数据。

3. 将曲线图元按照指定精度近似拟合为多段线。

4. 统计源文件中的图元类型及各类型的数量。

5. 以 SAM 插件形式提供图形化操作界面。

6. 支持设置导入基点，使 CAD 图纸与 SAM 中的目标位置对齐。

7. 对整体处理过程提供状态反馈，并对导入、转换和创建过程中出现的问题提供明确的错误提示及日志记录。

### 2\.4 运行环境和依赖

- 插件运行于 SAM 软件环境中。

- 输入文件为 DXF 文件。

- 插件依赖 SAM 提供的插件加载机制以及点、线或多段线创建接口。

- DXF 文件应满足本报告第 7 章所述的约束和假设。

## 3\. 业务需求

|编号|业务需求|说明|
|---|---|---|
|BR\-01|DXF 文件导入与解析|系统必须支持用户选择并读取 DXF 文件，并解析其中处于支持范围内的几何图元。|
|BR\-02|SAM 数据转换|系统必须将解析后的 DXF 数据转换为 SAM 可使用的数据。|
|BR\-03|曲线近似拟合|系统必须将 DXF 中无法直接导入的曲线近似拟合为 SAM 可使用的多段线。|
|BR\-04|图元分类统计、异常统计与离散化最大偏差|系统必须输出源文件包含的图元类型数量及每种类型的图元数量，同时输出转换过程中出现的异常和离散化产生的最大偏差。|
|BR\-05|插件化和图形界面|系统必须以插件形式集成到 SAM 中，并提供图形化操作界面。|

## 4\. 功能需求

### 4\.1 DXF 文件选择与解析

**需求编号：FR\-01**

1. 系统应提供 DXF 文件选择入口，允许用户从本地选择待导入文件。

2. 系统应在解析前检查文件是否存在、是否可读、扩展名是否为 `.dxf`，并检查文件格式是否属于当前支持范围。

3. 系统应解析文件中处于支持范围内的点、线、多段线及曲线类图元。

4. 系统遇到不支持的图元时，应记录图元类型和相关信息，并向用户给出提示，不得无提示地忽略。

5. 文件无法读取或解析失败时，系统应停止本次导入并显示明确的错误信息。

### 4\.2 曲线的多段线近似拟合

**需求编号：FR\-02**

1. 系统应对不能直接转换为 SAM 几何对象的曲线执行多段线近似拟合。

2. 拟合结果应保持原曲线的基本形状和起止位置。

3. 系统应记录原曲线与转换后多段线之间的对应关系。

4. 单条曲线转换失败时，系统应记录失败原因和图元信息，并按照既定异常处理策略继续或终止任务。

### 4\.3 倒角处理

**需求编号：FR\-03**

1. 系统应识别 DXF 几何中构成倒角的相关线段或曲线。

2. 系统应将倒角涉及的几何数据转换为符合 SAM 数据格式的点、线或多段线。

3. 转换后应尽量保持倒角原有的几何形状和连接关系。

4. 无法正确转换的倒角应在日志中标明，不得静默丢失。

### 4\.4 图元类型和数量统计

**需求编号：FR\-04**

1. 系统应统计 DXF 文件中识别到的图元类型总数。

2. 系统应统计每种图元类型对应的图元数量。

3. 统计结果应以源 DXF 图元为统计对象，转换后生成的点、线和多段线数量不进行统计。

4. 对于不支持或转换失败的图元，系统应分别统计其类型和数量。

5. 统计结果应在命令行中展示，并写入导入日志或结果摘要。

### 4\.5 SAM 数据转换与创建

**需求编号：FR\-05**

1. 系统应将解析、校验和拟合后的几何数据转换为 SAM 可识别的数据。

2. 系统应在 SAM 中创建相应的点与线对象。

3. 创建顺序应保证同一图元转换后各点和线段之间的关系正确。

4. SAM 对象创建失败时，系统应在命令行中明确显示创建失败的总数量及前十项失败原因，并在日志中记录全部失败原因和相关图元。

### 4\.6 导入基点设置

**需求编号：FR\-06**

1. 系统应允许用户设置 CAD 图纸导入后的基点位置，即指定 CAD 零点在 SAM 中对应的位置。

2. 系统应根据用户设置的基点，对所有待导入几何对象进行统一平移。

3. 未设置基点时，系统应将 CAD 世界坐标系原点映射到 SAM 世界坐标系原点。

4. 平移操作不应改变图纸内部各图元之间的相对位置和几何尺寸。

### 4\.7 图形化操作界面

**需求编号：FR\-07**

图形界面至少应提供以下信息和操作：

- 选择待导入的 DXF 文件；

- 设置或选择导入基点；

- 设置曲线拟合精度（若确认向用户开放）；

- 启动导入操作；

- 显示当前处理状态和导入结果；

- 展示图元类型及数量统计；

- 显示导致 DXF 文件导入失败的错误原因。

系统应防止用户在必要参数缺失或文件校验未通过时直接执行导入。

### 4\.8 日志和结果反馈

**需求编号：FR\-08**

1. 系统应记录每个图元是否成功解析和导入。

2. 系统应记录曲线是否已转换为多段线。

3. 系统应记录转换后新增的点和线，通过详细日志记录明细，并在界面中仅显示摘要。

4. 系统应记录处理过程中出现的错误、警告及其原因。

5. 日志应至少包含处理时间、源文件、处理阶段、图元类型、处理结果和错误原因等信息。

6. 一次导入完成后，系统应向用户展示成功数量、失败数量、跳过数量和转换后点线数量等结果摘要。

## 5\. 非功能需求

### 5\.1 易用性

**需求编号：NFR\-01**

- 插件应提供清晰的图形化操作界面，使用户能够完成文件选择、参数设置、导入和结果查看。

- 操作结果和当前状态应清晰可见。

- 输入有误时，应在用户执行导入前尽可能给出提示。

### 5\.2 错误处理

**需求编号：NFR\-02**

- DXF 文件存在问题时，系统必须提供明确的报错信息。

- 错误信息应说明发生错误的处理阶段、可能原因及建议用户采取的处理措施。

- 对可跳过的单个图元错误，系统应记录后继续处理其他图元；对导致文件整体不可用的错误，系统应终止本次导入。

建议至少区分以下错误场景：文件不存在、文件无法读取、文件格式不支持、DXF 版本不符合要求、文件内容损坏、图元不支持、几何数据无效、曲线拟合失败以及 SAM 对象创建失败。

### 5\.3 可追溯性

**需求编号：NFR\-03**

- 日志应能够追踪每个源图元的解析、转换和导入结果。

- 曲线转换日志应能够说明该曲线是否已转为多段线，以及生成了哪些点和线。

- 日志信息应与统计结果保持一致，便于问题定位和验收核对。

### 5\.4 性能与响应

**需求编号：NFR\-04**

- 系统处理图纸时应向用户显示必要的状态或进度，避免用户误认为程序无响应。

- 系统应能够处理项目实际使用的船舶 CAD 图纸；具体文件规模和处理时限应根据典型样例确定，并纳入验收标准。

### 5\.5 数据准确性

**需求编号：NFR\-05**

- 导入后图形的相对位置、尺寸关系和连接关系应与原 CAD 图纸保持一致。

- 曲线拟合误差不得超过最终确认的精度阈值。

- 图元类型和数量统计应与系统实际识别及处理的结果一致。

## 6\. 约束与假设

### 6\.1 技术约束

1. 当前版本不支持DWG格式文件。

2. 当前版本以 AutoCAD 2018 版本的 DXF 文件为目标格式；其他版本文件的兼容性不作保证。

3. 系统通过 SAM 插件形式运行，具体实现受 SAM 插件接口和几何创建能力约束。

### 6\.2 业务假设

1. 假设用户提供的 DXF 图纸采用世界坐标系，坐标单位为毫米。

2. 若用户使用自定义坐标系，应在导入前将图纸转换为世界坐标系。

3. 假设输入文件中的几何数据完整、有效，且不存在需要插件自动修复的严重几何错误。

4. 假设用户有权限读取所选 DXF 文件，并有权限在当前 SAM 工程中创建几何对象。

### 6\.3 外部依赖

1. SAM 软件能够加载和运行本插件。

2. SAM 提供创建点、线或多段线所需的接口。

3. SAM 的坐标系、单位和插件接口信息能够在设计与开发阶段获得确认。

## 7\. 不包含范围

本期需求不包括以下内容：

1. 不解析块和外部依赖。若图纸中包含块或外部依赖，用户应在导入前手动将其炸开或转换为基础图元。

2. 不解析螺旋、圆环和修订曲线。

3. 不解析图层语义，也不导入尺寸标注。

4. 不保证 AutoCAD 2018 以外 DXF 版本的兼容性。

5. 导入 DXF 图纸时，不支持对坐标进行旋转变换。

## 8\. 验收标准

|编号|对应需求|验收标准|
|---|---|---|
|AC\-01|FR\-01|对符合约束的 DXF 测试文件，系统能够完成读取和解析，并识别支持范围内的图元。|
|AC\-02|FR\-02|曲线能够转换为连续多段线，起止位置正确，拟合误差满足最终确认的精度要求。|
|AC\-03|FR\-03|测试图纸中的倒角能够按 SAM 格式生成，形状及连接关系与原图基本一致。|
|AC\-04|FR\-04|系统输出的图元类型及数量与测试文件预期值一致；转换前后的统计口径清晰。|
|AC\-05|FR\-05|转换后的点、线或多段线能够在 SAM 中成功创建和显示。|
|AC\-06|FR\-06|设置基点后，导入图形整体移动到指定位置，内部相对位置和尺寸保持不变。|
|AC\-07|FR\-07|用户能够通过图形界面完成文件选择、参数设置、导入和结果查看。|
|AC\-08|FR\-08、NFR\-03|日志能够反映各图元的解析、转换和导入结果，并记录曲线转换生成的点线信息。|
|AC\-09|NFR\-02|使用无效或不支持的文件测试时，系统能够显示明确错误，不出现无提示退出。|
|AC\-10|NFR\-05|导入结果的坐标、尺寸、连接关系和统计数据满足已确认的准确性要求。|

## 9\. 已确认及待确认事项

以下事项包含当前已经确认的结论及仍需由需求方、开发方和 SAM 接口负责人共同确认的内容：

1. 曲线拟合采用的精度指标、默认值以及用户是否可以在界面中修改，待结合 OCC 相关内容进一步确认。

2. 需要支持的 DXF 图元类型完整清单，以及倒角的具体识别和处理规则，待后续补充。

3. 典型 DXF 文件大小、最大图元数量、期望处理时间和可接受内存占用目前尚无明确指标，暂不作具体规定。等到跑通流程后再回来做规定。
