## 1. 整体架构

```
┌──────────────────────────────────────────────────────────────┐
│                    Python 脚本层 / GUI                        │
│  session.journal('Example1').importDxf(path)                  │
│  Example1DXFImportDialog (浏览 → 校验 → 发送命令)              │
└──────────────────────┬───────────────────────────────────────┘
                       │
┌──────────────────────▼───────────────────────────────────────┐
│                Example1PytModule (pyoModule)                   │
│    importDxf() → 解析 → 转换 → SamBuilder → 场景展示           │
└──────────────────────┬───────────────────────────────────────┘
                       │
          ┌────────────┼────────────────┐
          │            │                │
          ▼            ▼                ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│   DxfParser  │ │ConversionEng.│ │  SamBuilder  │
│ parseFile()  │ │  convert()   │ │beginImport() │
└──────┬───────┘ └──────┬───────┘ │createLines() │
       │                │         │createPoints()│
┌──────▼───────┐ ┌──────▼───────┐ │createCircles()│
│  DxfReader   │ │   SamData    │ │  commit()    │
│(DRW_Interface│ │ (就绪数据)    │ └──────────────┘
│   回调)       │ └──────────────┘
└──────┬───────┘
       │
┌──────▼───────┐
│   DxfData    │
│  (原始数据)   │
└──────┬───────┘
       │
┌──────▼───────┐
│  libdxfrw    │
│ (第三方解析库) │
└──────────────┘
```

**数据流：** DXF 文件 → `libdxfrw` 解析 → `DxfReader` 回调 → 填充 `DxfData` → `DxfParser` 返回 → `ConversionEngine::convert()` 基点平移并过滤 → `SamData` → `SamBuilder` 创建 SAM 草图几何 → 提交数据库 → 场景展示。

**职责分离：**
| 组件 | 职责 |
|------|------|
| `DxfParser` / `DxfReader` | DXF 文件读取与解析 |
| `DxfData` | 原始解析结果的容器 |
| `ConversionEngine` | 坐标平移 + 无效图元过滤 |
| `SamData` | 转换后就绪数据的容器 |
| `SamBuilder` | SAM 平台交互（草图创建、几何生成、提交、场景展示） |
| `Example1PytModule` | 顶层调度，串联上述组件 |
| `Example1DXFImportDialog` | GUI 对话框，浏览文件并触发导入 |

## 2. 数据模型 — DxfData

数据模型定义在 `DxfData.h` / `DxfData.cpp` 中，采用类层次结构表示 DXF 实体。

### 2.1 实体类型枚举 EntityType

```cpp
enum class EntityType {
    Point,   // 点
    Line,    // 线段
    Circle   // 圆
};
```

用于运行时标识 `DxfEntity` 的具体子类类型。

### 2.2 DxfEntity 抽象基类

所有 DXF 实体的基类，提供**自动递增 ID**。

```cpp
class DxfEntity {
public:
    DxfEntity(EntityType entityType);
    virtual ~DxfEntity() = default;

    int getId() const;          // 获取唯一标识 ID（全局自增，从 1 开始）
    EntityType getType() const; // 获取实体类型

    virtual bool isValid() const = 0;  // 子类实现有效性检查

private:
    int id;
    EntityType type;
};
```

| 方法 | 说明 |
|------|------|
| `getId()` | 返回全局自增整数 ID（从 1 开始，每次构造递增） |
| `getType()` | 返回 `EntityType` 枚举值 |
| `isValid()` | 纯虚函数，子类各自实现有效性规则 |

### 2.3 DxfPoint

表示三维空间中的一个点坐标，同时也是一个可复用的值类型（`DxfLine` 和 `DxfCircle` 内部使用它）。

```cpp
class DxfPoint : public DxfEntity {
public:
    DxfPoint();
    DxfPoint(double ix, double iy, double iz);

    double x() const;
    double y() const;
    double z() const;

    void setX(double v);
    void setY(double v);
    void setZ(double v);

    bool isValid() const override;  // 三轴均为有限浮点数
};
```

| 成员 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `x`, `y`, `z` | `double` | `0.0` | 三维坐标 |

**有效性规则：** `std::isfinite(x) && std::isfinite(y) && std::isfinite(z)`。

### 2.4 DxfLine

表示一条由起点和终点确定的线段。

```cpp
class DxfLine : public DxfEntity {
public:
    DxfLine();
    DxfLine(const DxfPoint& start, const DxfPoint& end);

    const DxfPoint& start() const;  // 起点
    const DxfPoint& end()   const;  // 终点

    bool isValid() const override;   // 起点终点均有效且不重合
};
```

| 成员 | 类型 | 说明 |
|------|------|------|
| `m_start` | `DxfPoint` | 起点 |
| `m_end` | `DxfPoint` | 终点 |

**有效性规则：** 起点和终点均 `isValid()`，且至少有一个坐标分量不同（非零长度线）。

### 2.5 DxfCircle

表示一个由圆心和半径确定的圆。

```cpp
class DxfCircle : public DxfEntity {
public:
    DxfCircle();
    DxfCircle(const DxfPoint& center, double radius);

    const DxfPoint& center() const;  // 圆心
    double radius()          const;  // 半径

    bool isValid() const override;   // 圆心有效、半径有限且 > 0
};
```

| 成员 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `m_center` | `DxfPoint` | `(0,0,0)` | 圆心坐标 |
| `m_radius` | `double` | `0.0` | 半径 |

**有效性规则：** 圆心 `isValid()` 且 `std::isfinite(radius) && radius > 0.0`。

### 2.6 DxfData 容器

顶层数据容器，管理三种实体的集合和解析状态。

```cpp
class DxfData {
public:
    DxfData() = default;

    // --- 修改器 ---
    void addPoint(const DxfPoint& pt);
    void addLine(const DxfLine& line);
    void addCircle(const DxfCircle& circle);
    void clear();

    // --- 访问器 ---
    const std::vector<DxfPoint>&  points()  const;
    const std::vector<DxfLine>&   lines()   const;
    const std::vector<DxfCircle>& circles() const;

    int entityCount() const;  // lines().size() + circles().size()

    // --- 错误 / 状态 ---
    QString errorMessage() const;
    void setErrorMessage(const QString& msg);

    bool isValid() const;
    void setValid(bool v);
};
```

| 方法 | 返回值 | 说明 |
|------|--------|------|
| `addPoint(pt)` | `void` | 添加一个点实体 |
| `addLine(line)` | `void` | 添加一条线段 |
| `addCircle(circle)` | `void` | 添加一个圆 |
| `clear()` | `void` | 清空所有实体、错误消息，重置 `isValid=false` |
| `points()` | `const std::vector<DxfPoint>&` | 获取所有点的只读引用 |
| `lines()` | `const std::vector<DxfLine>&` | 获取所有线段的只读引用 |
| `circles()` | `const std::vector<DxfCircle>&` | 获取所有圆的只读引用 |
| `entityCount()` | `int` | 返回 `lines().size() + circles().size()` |
| `errorMessage()` | `QString` | 获取错误消息 |
| `setErrorMessage(msg)` | `void` | 设置错误消息 |
| `isValid()` | `bool` | 获取解析成功标志（默认 `false`） |
| `setValid(v)` | `void` | 设置解析成功标志 |

> **注意：** `entityCount()` 目前仅统计线段和圆，**不包含点**。

## 3. 解析器 — DxfParser

解析器定义在 `DxfParser.h` / `DxfParser.cpp` 中，基于 `libdxfrw` 库实现 DXF 文件读取。

### 3.1 DxfReader

`DxfReader` 继承自 `DRW_Interface`（`libdxfrw` 定义的回调接口），注册接收解析事件的回调。

```cpp
class DxfReader : public DRW_Interface {
public:
    DxfData m_data;  // 存储解析结果

    // 已实现回调
    void addLine(const DRW_Line& data) override;
    void addCircle(const DRW_Circle& data) override;
    void addLWPolyline(const DRW_LWPolyline& data) override;

    // 其他回调均为空实现（支持后续扩展）
};
```

**已实现的回调处理：**

| 回调 | 实体 | 处理逻辑 |
|------|------|----------|
| `addLine` | LINE | 将 `DRW_Line` 的 basePoint / secPoint 转为 `DxfLine` 并添加到 `m_data` |
| `addCircle` | CIRCLE | 将 `DRW_Circle` 的 basePoint / radious 转为 `DxfCircle` 并添加到 `m_data` |
| `addLWPolyline` | LWPOLYLINE | 将轻量多段线的相邻顶点分解为多条 `DxfLine`；闭合多段线首尾相连；跳过含弧形段（bulge ≠ 0）的顶点 |

**目前为空实现的回调（待扩展）：**

`addPoint`, `addArc`, `addEllipse`, `addSpline`, `addPolyline`, `addText`, `addMText`, `addInsert`, `addHatch`, `addSolid`, `add3dFace`, 以及所有 `write*` / `addDim*` / `addLeader` 等方法均为空实现。

**LWPOLYLINE 分解规则：**

1. 顶点数 < 2 → 跳过
2. 遍历 `i = 0` 到 `numVerts - 2`，取 `v1 = vertlist[i]`, `v2 = vertlist[i+1]`
3. 若 `v1.bulge != 0` 或 `v2.bulge != 0` → 跳过（弧形段暂不支持）
4. 否则将其作为直线段 `DxfLine(v1 → v2)` 加入
5. 若为闭合多段线 (`flags & 1`)，连接最后一个顶点到第一个顶点

### 3.2 DxfParser

解析入口类，提供单一静态风格的接口。

```cpp
class DxfParser {
public:
    bool parseFile(const QString& filePath, DxfData& outData);
};
```

#### `parseFile`

```cpp
bool DxfParser::parseFile(const QString& filePath, DxfData& outData);
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `filePath` | `const QString&` | DXF 文件路径 |
| `outData` | `DxfData&` | [输出] 解析结果容器 |

| 返回值 | 含义 |
|--------|------|
| `true` | 解析成功，且至少包含一条 LINE 实体 |
| `false` | 解析失败或文件中没有 LINE 实体 |

**处理流程：**

1. 检查路径是否为空 → 设置错误消息并返回 `false`
2. 转码为本地编码 → 创建 `dxfRW` 对象
3. 调用 `dxf.read(&reader, true)` → 若失败，提取错误码并设置错误消息
4. 将 `reader.m_data` 移到输出 → 设置 `isValid = true`
5. 检查 `lines().empty()` → 若无 LINE 实体，设置警告消息并返回 `false`
6. 返回 `true`

**可能出现的错误消息：**

| 错误消息 | 触发条件 |
|----------|----------|
| `"DXF file is empty"` | 文件路径为空字符串 |
| `"Failed to read DXF file. Error code: %1"` | `dxf.read()` 返回 false |
| `"DXF was read successfully, but no LINE entities were found."` | 成功读取但无 LINE 实体 |

## 4. 转换引擎 — ConversionEngine

**所在文件：** `src/Example1/ConversionEngine.h` / `ConversionEngine.cpp`

转换引擎位于解析层和 SAM 构建层之间，负责将 `DxfData` 转换为 `SamData`。

### 4.1 ConversionEngine 类

```cpp
class ConversionEngine {
public:
    ConversionEngine() = default;

    // 主入口：DxfData → SamData
    // baseX/Y/Z：CAD 原点平移到的基点位置
    // 返回 true 表示至少成功转换了一个图元
    bool convert(const DxfData& dxfData,
                 double baseX, double baseY, double baseZ,
                 SamData& outData);

private:
    static DxfPoint translate(const DxfPoint& pt,
                              double bx, double by, double bz);
};
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `dxfData` | `const DxfData&` | DxfParser 解析输出的原始数据 |
| `baseX/Y/Z` | `double` | 基点偏移量（CAD 原点平移到此处） |
| `outData` | `SamData&` | [输出] 转换后的就绪数据 |

### 4.2 处理流程

对三类图元依次过滤 + 平移：

| 图元类型 | 处理方式 |
|----------|----------|
| Point | 若 `isValid()`，平移后写入 SamData |
| Line | 若 `isValid()`，平移起点和终点后写入 SamData |
| Circle | 若 `isValid()`，平移圆心后写入 SamData（半径不变） |

无效图元（零长线段、零半径圆、非有限坐标点等）直接跳过。

> **后续迭代计划（未实现）：** 对圆弧、样条曲线、椭圆等曲线类型，调用 `CurveDiscretizer`（基于 OCC）离散化为线段后再写入 SamData。

### 4.3 基点平移

所有坐标统一偏移：

```
SamPoint = DxfPoint + (baseX, baseY, baseZ)
```

不改变图元之间的相对位置和尺寸。当前 `importDxf` 调用时基点参数均为 `0.0`（不做平移）。

## 6. SAM 构建器 — SamBuilder

**所在文件：** `src/Example1/SamBuilder.h` / `SamBuilder.cpp`

`SamBuilder` 封装了与 SAM 平台的所有交互，包括草图创建、几何生成、数据库提交和场景展示。它将原来散落在 `importDxf` 中的 SAM 相关代码抽取为独立组件，实现关注点分离。

### 6.1 SamBuilder 类

```cpp
class SamBuilder {
public:
    SamBuilder();
    ~SamBuilder();

    // 生命周期管理
    bool beginImport(const QString& modelName = "Model-1");
    bool commit();
    void rollback();

    // 几何创建
    int createPoints(const std::vector<DxfPoint>& points);
    int createLines(const std::vector<DxfLine>& lines);
    int createCircles(const std::vector<DxfCircle>& circles);

    // 状态查询
    int createdCount() const;
    const QString& sketchName() const;
    const QString& lastError() const;
};
```

| 方法 | 返回值 | 说明 |
|------|--------|------|
| `beginImport(modelName)` | `bool` | 开始导入会话：创建草图 `DxfImport_<timestamp>` 和 `skcGeomFactory` |
| `createPoints(points)` | `int` | 在草图中创建点几何（当前为桩代码，待 SAM 接口就绪） |
| `createLines(lines)` | `int` | 在草图中创建线段几何，同时扩展包围盒 |
| `createCircles(circles)` | `int` | 在草图中创建圆几何（当前为桩代码，待 SAM 接口就绪） |
| `commit()` | `bool` | 提交：调整 SheetSize → 插入草图仓库 → 替换 Basis → 清空撤销栈 → 切换 PART 视图 → 刷新场景 → 设置主对象路径 |
| `rollback()` | `void` | 回滚：重置所有状态，不产生任何副作用 |
| `createdCount()` | `int` | 返回已创建的图元总数 |
| `sketchName()` | `const QString&` | 返回草图名称（如 `DxfImport_1712345678901`） |
| `lastError()` | `const QString&` | 返回最后一次错误消息 |

### 6.2 生命周期

```
beginImport() ──→ createLines/Points/Circles (可多次调用) ──→ commit()
                    │
                    └── 失败时 → rollback()
```

- `beginImport()` 创建草图并初始化 `skcGeomFactory`，设置 `m_active = true`
- 几何创建方法仅在 `m_active == true` 时生效
- `commit()` 执行后 `m_active = false`，不可再添加几何
- `rollback()` 可在任何时候调用，重置所有状态

### 6.3 草图尺寸自动计算

`SamBuilder` 在 `createLines()` 中自动追踪所有导入几何的包围盒（bounding box），在 `commit()` 时根据包围盒自动设置草图 SheetSize：

```
extent = max(|minX|, |maxX|, |minY|, |maxY|) × 2.4
SheetSize = max(extent, 200.0)
```

这确保导入的图纸不会超出草图可视范围，且最小尺寸为 200.0（保持与手动创建草图一致）。

## 7. Python 绑定 — Example1PytModule

DXF 导入功能通过 `Example1PytModule` 注册为 SAM 的 Python 可调用方法。该类继承自 `pyoModule`，注册了三个方法。

**方法注册表：**

```cpp
static omuInterfaceObj::methodTable Example1PytModuleMethods[] = {
    {"calcArea",   &Example1PytModule::calcArea},
    {"createLine", &Example1PytModule::createLine},
    {"importDxf",  &Example1PytModule::importDxf},
    {0, 0}
};
```

### 7.1 `importDxf` 方法

```python
session.journal('Example1').importDxf(filePath)
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `filePath` | `str` | DXF 文件的完整路径 |

| 返回值 | 类型 | 含义 |
|--------|------|------|
| `int` | `omuPrimNumber` | 成功创建的图元总数；解析失败返回 `None`；无有效图元返回 `0` |

**内部流程（三阶段）：**

1. **阶段 1 — DXF 解析**
   - 调用 `DxfParser::parseFile()` 解析文件
   - 输出 `DxfData`（原始坐标）
   - 解析失败 → 返回 `nullptr`（Python 端收到 `None`）

2. **阶段 2 — 转换引擎**
   - 调用 `ConversionEngine::convert(dxfData, 0.0, 0.0, 0.0, samData)`
   - 基点平移 + 过滤无效图元（当前基点均为 0，不做平移）
   - 输出 `SamData`（坐标就绪）
   - 无有效图元 → 返回 `0`

3. **阶段 3 — SAM 构建**
   - 创建 `SamBuilder` 实例
   - 调用 `builder.beginImport()` 创建草图
   - 调用 `builder.createPoints(lines/circles)` 创建几何
   - 调用 `builder.commit()` 提交数据库并刷新场景
   - 失败时调用 `builder.rollback()` 回滚

## 11. 扩展指南

### 添加新的实体类型

1. 在 `EntityType` 枚举中新增类型（如 `Arc`）
2. 新建继承 `DxfEntity` 的子类，实现 `isValid()`
3. 在 `DxfData` 中添加对应的 `std::vector<T>` 成员和 `addXxx()` / `xxx()` 方法
4. 在 `DxfReader` 中实现对应的 `addXxx(const DRW_Xxx&)` 回调
5. 在 `ConversionEngine` 中添加对应的处理逻辑
6. 在 `SamBuilder` 中添加对应的 `createXxx()` 方法
7. 在 `Example1PytModule::importDxf()` 中调用新的 `SamBuilder` 方法

### 支持 LWPOLYLINE 弧形段

当前弧形段（bulge ≠ 0）被跳过。如需支持，可在 `DxfReader::addLWPolyline()` 中根据 bulge 值计算弧的圆心、半径和角度范围，生成圆弧实体，再由 `ConversionEngine` 调用 `CurveDiscretizer`（基于 OCC，尚未实现）离散化后传入 SAM。

### 接入 Point / Circle 的 SAM 创建接口

当前 `SamBuilder::createPoints()` 和 `createCircles()` 为桩代码（仅计数，不实际创建几何）。待 SAM 平台提供对应的 `skcGeomFactory::CreatePoint` / `CreateCircle` 接口后，参照 `createLines()` 的实现方式接入。
