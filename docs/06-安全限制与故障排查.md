# 安全限制与故障排查

## 1. 资源限制

### C++ 与 Web DXF

| 限制 | 值 |
|---|---:|
| Small 最终输出 | 100,000 |
| Large 最终输出 | 500,000 |
| 单个 INSERT 阵列实例 | 100,000 |
| 累计展开块实例 | 100,000 |
| C++ 块递归深度 | 32 |
| 浏览器输入文件 | 50 MB |

Unlimited 不限制最终输出数量，但仍保留 INSERT 结构限制。不要用 Unlimited 处理来源不可信的文件。

### Agent 服务

| 限制 | 值 |
|---|---:|
| 请求体 | 16 MiB |
| 点线总数 | 100,000 |
| 检查分页 | 每页最多 200 |
| Agent 循环 | 最多 8 步 |
| 上游总超时 | 30 秒 |
| 上游响应体 | 4 MiB |
| 几何缩放倍率 | 大于 0 且不超过 1,000,000 |

## 2. 常见错误码

| 错误码 | 含义 | 首要检查 |
|---|---|---|
| `INVALID_ARGUMENT` | 参数、坐标或公差无效 | NaN/Inf、公差范围、输出档位 |
| `READ_FAILED` | DXF 无法读取 | 路径、权限、文件编码/格式 |
| `EXPANSION_LIMIT` | BLOCK/INSERT 超限 | 阵列数量、嵌套层数、档位 |
| `CONVERSION_LIMIT` | 离散/FE 最终输出超限 | 公差过小、图纸档位 |
| `NO_SUPPORTED_ENTITIES` | 没有可转换实体 | 文件是否只含文字、填充或无效实体 |
| `CANCELED` | 用户取消 | 确认没有半成品并同名重试 |
| `BEGIN/CREATE/COMMIT_FAILED` | SAM 构建阶段失败 | 日志中的阶段和 Repository 状态 |
| `ROLLBACK_FAILED` | 补偿清理失败 | 保留根错误，重启前检查半成品对象 |

## 3. 构建失败

### 找不到 spdlog

设置 `SPDLOG_ROOT` 到包含 `share/spdlog/spdlogConfig.cmake` 或
`lib/cmake/spdlog/spdlogConfig.cmake` 的安装前缀。

### 找不到 libdxfrw

`LIBDXFRW_ROOT` 必须同时包含源码头文件和已构建的 Release `.lib/.dll`。本项目不会在
配置阶段自动构建 libdxfrw。

### Qt 或 SAM 符号不匹配

优先使用 SAMSDK 附带的 Qt 和已验证的 VS2017 x64 工具集。混用 Qt、编译器或 Debug/Release
库可能配置成功但在加载插件时失败。

### C4828/C5033

Qtitan 的 C4828 和 Python 2.7 头文件的 C5033 是已知第三方警告。项目源码出现新的编译
警告仍应单独处理，不能一概归为第三方问题。

## 4. SAM 导入失败

1. 在 `logs/imports/` 找到最新 `dxf_import_<id>.log`；
2. 查看 `logs/dxf_import_errors.log` 的阶段、错误码和回滚结果；
3. 用 `block_test_minimal.dxf` 区分环境问题和图纸问题；
4. FE 模式确认目标模型存在、Part 名非空且无未清理同名对象；
5. 超限时先选择 Large 或增大合理公差，不要直接使用 Unlimited；
6. 取消/失败后检查 Repository，再使用同名重试验证回滚。

## 5. Unicode 路径失败

项目会自动把 libdxfrw 无法表示的路径暂存到 ASCII 临时目录。若仍失败，检查：

- 源文件实际存在且为普通文件；
- 临时目录可写；
- 安全软件没有阻止暂存副本；
- 日志是否报告暂存复制或清理错误。

不要手工把用户文件重命名为 ASCII 作为永久解决方案。

## 6. Web Agent 失败

### 无法连接本地服务

- 确认已运行 `npm.cmd start`；
- 检查 8080 或 18080；
- 如果显式设置了 `PORT`，前端默认回退列表不会自动知道任意新端口；
- Live Server 页面仍需要独立启动本地 Agent 服务。

### 403

通常是 Origin 端口不匹配或 CSRF Token 失效。刷新页面重新获取 `/api/session`，并确认
页面与服务使用同一 loopback 端口。

### 413

请求体超过 16 MiB、几何超过 100,000 点线，或输入 DXF 超过浏览器 50 MB。减少工作副本，
不要绕过服务端边界。

### 502/504

分别表示上游连接/响应问题或 30 秒超时。服务不会回传上游错误正文，需结合提供商状态、
端点、模型名和本地网络检查。

## 7. 密钥处理

- 优先使用服务端环境变量；
- 不把 API Key 写入源码、文档、日志或浏览器持久存储；
- 自定义端点使用请求级密钥；
- 服务端密钥不会发送到请求指定的自定义地址；
- 清除 Agent 配置后应确认密钥输入框为空。
