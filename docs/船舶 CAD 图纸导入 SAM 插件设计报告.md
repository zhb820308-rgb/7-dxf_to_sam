# 船舶 CAD 图纸导入 SAM 插件设计报告

# 在该文档下，我们不确定质量目标和效率目标的中的0\.1mm和100MB文件解析时间≤ 30 秒是否为最后准确值，我们需要根据真实的项目数据进行确认

## 1\. 项目概述

### 1\.1 建设背景

船舶设计与制造过程中，大量图纸以 AutoCAD DXF 格式存在。这些图纸需要在 SAM（Ship Analysis Model）平台中进行三维建模和 CAE 分析。当前缺少一条从 DXF 图纸到 SAM 模型的自动化转换通道，依赖人工重新建模，效率低且易出错。

本项目旨在开发一套 DXF → SAM 的自动转换工具，以插件形式运行于 SAM 软件中，解决船舶图纸中直线、圆弧、样条曲线等几何的解析与重建问题。

### 1\.2 建设目标

|目标|说明|
|---|---|
|核心目标|将DXF二维图纸几何图元转换为SAM三维空间线框草图，完整还原基础点、直线、圆，复杂曲线离散为多段线|
|质量目标|曲线拟合偏差 ≤ 0\.1 mm（可配置）；不因任何 DXF 文件崩溃|
|效率目标|100MB 文件解析时间 ≤ 30 秒|
|易用目标|提供图形化界面，支持选择导入基点|

### 1\.3 用户场景

|用户|场景|需求|
|---|---|---|
|CAE 工程师|将 CAD 图纸导入 SAM 进行结构分析|完整还原图纸几何，支持基点定位|
|项目验收方|批量验证多张图纸的转换效果|统计数据清晰，异常可追溯|

### 1\.4 范围与约束

**处理范围：**

|图元类型|处理方式|优先级|
|---|---|---|
|点（POINT）|直接映射为 SAM 点|P0|
|直线 \(LINE\)|直接映射为 SAM 直线|P0|
|圆 \(CIRCLE\)|直接调用 SAM 的画圆接口|P0|
|多段线 \(LWPOLYLINE\)|解析顶点序列后逐段绘制|P0|
|圆弧 \(ARC\)|离散化为多段线后逐段绘制|P1|
|样条曲线 \(SPLINE\)|调用 OCC 库离散化为多段线|P1|
|椭圆/椭圆弧 \(ELLIPSE\)|调用 OCC 库离散化为多段线|P1|
|倒角 \(CHAMFER\)|解析并转换为 SAM 格式|P1|

**不包含范围：**

- 不包含对块（BLOCK）和外部依赖的解析；若图纸中包含块或外部依赖，用户需在导入前手动将其炸开

- 不对螺旋线、圆环与修订曲线进行解析

- 不包含对图层进行解析，不包含尺寸标注

**技术约束：**

- 必须通过 SAM 的 skcGeomFactory 接口（CreatePoint / CreateLine / CreateCircle）绘制

- 使用 OCC 作为 DXF 解析库

- 曲线离散化基于 OpenCASCADE（OCC）数学库

- C\+\+ 开发，CMake 构建，Qt 做 GUI

- 以插件形式在 SAM 软件中运行

- 以 AutoCAD 2018 版本的 DXF 文件为目标格式；其他版本存在兼容性风险，但经用户确认后允许继续导入

- 假设用户使用世界坐标系，且单位为毫米

### 1\.5 术语定义

|术语|说明|
|---|---|
|DXF|AutoCAD 的开放图纸交换格式|
|SAM|Ship Analysis Model，三维建模/CAE 平台|
|图元|DXF 中的基本几何对象（LINE, ARC, CIRCLE 等）|

|基点|用户指定的 CAD 原点在 SAM 场景中的放置位置|
|MVP|最小可行性产品，第一迭代目标|

### 3\.2 曲线离散化模块（基于 OCC）

**职责范围：** 将圆弧、样条曲线、椭圆等曲线图元离散化为 SAM 能处理的直线段集合。

本模块基于 OpenCASCADE（OCC）几何建模内核实现曲线离散化。OCC 提供成熟的几何处理接口，能够保证离散化精度和稳定性，避免自研算法带来的维护成本。

#### 圆与圆弧的处理策略

- **完整圆（360° 闭合）**：不进行离散化，直接调用 SAM 的 CreateCircle 接口。这是最优方案，因为 SAM 原生支持圆，且能保证精度和性能。

- **非完整圆弧**：SAM 的 CreateCircle 不支持绘制圆弧，因此需要将圆弧离散化为多段线。基于 OCC 的 `GCPnts_QuasiUniformDeflection`，将圆弧按设定的角度步长采样为点列，再通过 CreateLine 逐段连接。

#### 样条曲线的离散化

样条曲线（Spline/NURBS）是本项目的难点。采用 OpenCASCADE 库提供的离散化接口进行处理：

1. OCC 的 `GCPnts_QuasiUniformDeflection` 可将样条曲线离散化为满足指定精度的多段线

2. OCC 内部采用自适应的离散化算法，能够自动在曲率大的区域加密采样点，在平直区域减少采样点

3. 离散化精度通过参数控制（默认 0\.1mm）

使用 OCC 的优势：

- **成熟可靠**：OCC 是工业级几何内核，离散化算法经过大量验证

- **精度可控**：直接控制离散化偏差上限

- **省去自研成本**：无需实现 Douglas\-Peucker 等算法，避免重复造轮子

|参数|默认值|说明|
|---|---|---|
|离散化容差|0\.1 mm|越小越精确，但点数越多|
|角度步长（圆弧）|5°|控制圆弧离散化密度|

#### 椭圆/椭圆弧的离散化

椭圆基于 OCC 的 `Geom_Ellipse` 类，通过参数方程采样实现离散化。OCC 提供的 `GCPnts_QuasiUniformDeflection` 可用于均匀或自适应采样。

### 3\.3 几何转换引擎模块

**职责范围：** 负责将解析后的 DXF 数据转换为 SAM 中的几何模型。

本模块是整个系统的调度中心，处理顺序如下：

**基点选择功能说明：**

船舶 CAD 图纸的坐标原点可能远离模型本身（例如大地坐标系下的偏移），而 SAM 希望在模型原点附近操作。因此提供用户手动选择导入基点的功能：

- **输入方式**：在 GUI 界面中输入基点的 X、Y、Z 坐标值，或在 SAM 场景中拾取一个点作为基点

- **效果**：CAD 图纸的原点（0,0,0）将被放置到用户指定的基点位置

- **默认值**：若用户未指定，默认以 \(0,0,0\) 为基点

这样做相比自动归一化的优势：

- 用户对导入位置有完全的控制权

- 避免自动偏移导致的意外结果

- 适合分块图纸的精确拼接场景

### 3\.4 统计模块

**职责范围：** 统计转换过程中的各类数据，生成可读报告。

报告内容分为以下维度：

- **曲线统计**：曲线图元的原始数量

- **异常统计**：被跳过的异常图元数量、类型和原因

- **质量指标**：离散化的最大偏差

输出格式支持界面直接展示和日志文件保存两种方式。

### 3\.5 日志模块

日志模块提供四个级别输出：

|级别|颜色|使用场景|
|---|---|---|
|DEBUG|灰色|开发调试信息，如"正在离散化样条曲线"|
|INFO|绿色|正常流程信息，如"解析完成，共 209 个图元"|
|WARNING|黄色|警告，如"跳过零长度直线 \(id=42\)"|
|ERROR|红色|错误，如"文件不存在，errno=2"|

功能设计要求：

- 控制台和日志文件双路输出

- 日志文件保存至 SAM 文件夹下的 `log` 文件夹，文件扩展名为 `.log`

- 每次导入生成一次日志记录；暂按累计超过 50 次时自动清理较早日志、保留最近 50 次导入日志设计。

- 崩溃时自动 flush，确保最后一条日志不丢失

### 3\.6 SAM 对接模块

**职责范围：** 对接 SamDraw 模块（C\+\+ \.pyd），完成最终的几何绘制。

该模块是对 SamDraw 模块的上层封装。SamDraw 模块已提供三个核心接口：

```Plaintext
createPoint(x, y, z)        → 返回点 ID
createLine(x1,y1,z1, ...)   → 返回线 ID  
createCircle(cx,cy,cz, r)   → 返回圆 ID
```

对接模块在此基础上增加：

- **草图生命周期管理**：每次导入使用新的独立草图，名称基于时间戳，不干扰已有内容

- **延迟刷新**：所有图元创建完成后统一刷新场景

- **导入事务管理**：单个图元创建失败但不影响后续处理时跳过该图元并继续；发生不可恢复错误时终止导入，并通过删除本次独立草图或调用 SAM 撤销能力，撤销本次导入已创建的全部对象

- **接口确认**：当前点、线和圆的创建方式为初步设计，SAM 目标版本、插件接口、几何数据格式及点线创建方式需在开发对接前最终确认

## 4\. 数据设计

### 4\.1 核心数据模型

系统定义两类数据容器，分别服务于解析阶段和转换阶段。

**解析数据（DxfData）—— 解析引擎的输出：**

```Plaintext
struct DxfData {
    vector<Point>    points;      // 点列表
    vector<Line>     lines;       // 直线列表
    vector<Circle>   circles;     // 圆列表（含完整圆）
    vector<Arc>      arcs;        // 圆弧列表（需离散化）
    vector<Spline>   splines;     // 样条曲线列表（需 OCC 离散化）
    vector<Polyline> polylines;   // 多段线列表
    vector<Ellipse>  ellipses;    // 椭圆列表（需离散化）
};
```

**就绪数据（SamData）—— 转换引擎的输出（可直接对接 SAM）：**

```Plaintext
struct SamData {
    vector<Point>    points;     // 点列表（与 DxfData 中的点一一对应）
    vector<Line>     lines;      // 直线列表（含原始直线 + 离散化曲线产生的线段）
    vector<Circle>   circles;    // 圆列表（仅保留完整的圆）
};
```

### 4\.2 模块间接口

|接口标识|用途|调用时间|主要输入示例|正常输出|异常处理|
|---|---|---|---|---|---|
|**I\-01**|**解析 DXF 文件**|用户启动导入后调用|文件路径 `D:\\ship.dxf`、非 2018 版本是否继续导入|`DxfData`，包含原始点、线、圆、圆弧、样条等图元及文件版本信息|文件不存在、不可读或整体损坏时返回失败；非 2018 版本先由应用层提示用户确认|

|**I\-05**|**记录处理过程**|文件校验、解析、转换和 SAM 创建等阶段均可调用|日志级别、处理阶段、图元 ID、结果及原因|控制台信息和 SAM `log` 文件夹下的 `.log` 记录|日志写入失败时提示用户，但不应直接导致插件或 SAM 崩溃|

|对接层接口（暂定名称）|功能及调用时机|传给 SAM 的数据示例|SAM 返回结果|失败后的处理|

|**refreshScene**|全部可处理图元创建完成后，统一刷新 SAM 场景显示|当前场景或本次导入上下文|场景显示更新结果|刷新失败时提示用户并记录日志，不重复创建已经成功生成的图元|
|**rollbackImport**|发生不可恢复错误时，撤销本次导入创建的对象|本次导入的草图 ID、上下文或已创建对象 ID 列表|撤销成功或失败状态|若撤销失败，记录未删除对象，并明确提示用户进行人工检查|

## 5\. 测试策略

### 5\.1 测试层次与测试要点

测试按照单元测试、集成测试和端到端测试三个层次开展。三个层次的测试对象不同，具体划分如下：

|测试层次|测试对象|主要测试内容|验证重点|
|---|---|---|---|
|**单元测试**|可独立运行的函数或模块|曲线离散化、基点平移、数据转换、统计和异常判断|单个功能的计算结果是否正确|
|**集成测试**|插件内部多个模块组成的处理链路|DXF 解析、几何转换、SamData 生成、统计及日志之间的数据传递|模块组合后能否正确处理完整文件|
|**端到端测试**|用户界面、插件、SAM 接口和 SAM 场景组成的完整系统|从用户选择文件到 SAM 显示模型的全过程|真实操作下的功能、显示和异常恢复是否正确|

**单元测试层：** 使用 Google Test 对核心函数进行自动测试。重点覆盖零长度直线、零半径圆弧、极端坐标值、空数据、无效容差、字段缺失和离散点数不足等边界条件。

**集成测试层：** 使用不同类型的 DXF 文件，验证解析、转换、离散化、SamData 生成、统计和日志模块能否正确协同工作。

|测试文件或场景|内容特征|验证重点|
|---|---|---|
|`test_simple.dxf`|仅含直线和圆|解析、转换和 SamData 生成链路|
|`test_curves.dxf`|包含圆弧和样条曲线|OCC 离散化结果及最大偏差|
|`test_ship.dxf`|真实船舶图纸片段及混合图元|图元统计、转换完整性和整体可靠性|
|`test_malformed.dxf`|包含异常数据或缺失字段|可恢复图元能否跳过，不可恢复错误能否正确终止|
|`test_empty.dxf`|空文件|空数据处理和错误反馈|
|非 AutoCAD 2018 DXF|其他版本的有效 DXF 文件|兼容性风险识别及用户确认结果能否传递给解析模块|
|连续处理多个文件|依次执行多次导入|模块状态是否正确重置，统计和日志是否相互独立|
|100MB 以上 DXF|大文件及大量图元|解析时间、内存使用和处理稳定性|

**端到端测试层：** 在 SAM 中执行完整导入流程，测试用户可以直接观察和操作的系统行为。

|测试场景|验证重点|
|---|---|
|图形界面操作|文件选择、坐标输入、SAM 基点拾取、导入按钮、进度和结果显示是否正确|
|基本图元与混合图元导入|SAM 中生成的点、线、圆及离散曲线是否完整，位置和连接关系是否正确|
|SAM 交互|导入前后进行创建、移动和删除操作时，是否出现崩溃或 ID 冲突|
|异常文件与版本提示|弹窗内容是否准确，继续导入和取消操作是否有效|
|异常恢复|单图元失败时是否继续；不可恢复错误发生时是否终止并撤销本次导入|
|场景刷新|全部可处理图元创建后是否统一显示，是否出现遗漏或重复绘制|
|日志检查|日志目录、`.log` 格式、错误与警告内容及超过 50 次后的清理行为是否符合设计|

### 5\.2 验收标准

|指标|目标值|
|---|---|
|离散化最大偏差|≤ 设定容差的 1\.5 倍|
|100MB 文件解析时间|≤ 30 秒|
|异常图元跳过率|\< 总图元的 1%|
|程序崩溃率|0%（不因任何输入崩溃）|

## 6\. 迭代开发计划

按照 MVP 思路，分三阶段迭代：

### 第一迭代：核心管线打通（MVP）

**目标：** 实现从 DXF 到 SAM 的基本通道，能处理最简单的图纸。

**包含功能点：**

- 直线、圆的解析与绘制

- 基本统计输出（图元数量）

- 图形界面（文件选择、导入按钮）

- 日志系统

- 单元测试 \+ 集成测试

**交付物：** SAM 插件，可导入仅含直线和圆的 DXF，在 SAM 中正确画出对应图形。

### 第二迭代：复杂图纸支持

**目标：** 支持真实船舶图纸，包含曲线与倒角

**包含功能点：**

- 圆弧离散化（OCC）

- 样条曲线离散化（OCC）

- 椭圆/椭圆弧支持

- 基点选择功能

- 倒角处理

- 多维度统计报告

**交付物：** 可完整转换真实船舶图纸，曲线均正确还原。

### 第三迭代：产品化完善

**目标：** 提供完整的产品化体验。

**包含功能点：**

- 配置文件系统（持久化参数）

- 异常场景全面覆盖

- 性能优化

**交付物：** 带 GUI 的 SAM 插件。

## 7\. 风险与应对

|风险|发生概率|影响程度|应对措施|
|---|---|---|---|
|libdxfrw 无法解析特定版本 DXF|中|高|在解析层做抽象隔离，出现弹窗让用户重新导出一个适配版本的DXF文件|
|OCC 离散化精度不满足要求|低|中|提供容差参数由用户调节|
|SAM API 版本变更导致不兼容|低|高|与业务层严格解耦，优先使用通用中间数据|
|超大图纸（\>500MB）内存溢出|中|中|流式解析 \+ 分块处理|
