## 2. 主要修改

### 2.1 公共数值谓词

新增：

```text
src/Example1/DxfNumeric.h
```

提供无状态、内联的基础判断：

```text
isFinite
areFinite
isPositiveFinite
isNonNegativeFinite
isWithinInclusive
```

以下模块改为复用同一判断：

- DXF 实体合法性；
- libdxfrw 实体适配；
- Parser 参数边界；
- Sketch/FE 转换参数边界；
- 几何离散过程中的有限值保护；
- Python FE 节点提交前坐标检查；
- FE 空间索引的缩放坐标检查。

所有比较符和边界值保持不变，例如正半径仍要求 `> 0`，节点合并容差仍允许 `0`，曲线容差仍为闭区间 `[1e-12, 1000]`。

### 2.2 默认容差单一来源

`GeometryUtils` 的默认曲线容差及 `0.01` 防御性回退改为引用：

```cpp
DxfImportDefaults::kCurveTolerance
```

圆弧、椭圆、样条的离散公式和合法输入输出没有改变。

### 2.3 POINT 语义和统计

`DxfEntityStats` 新增：

```cpp
std::size_t points = 0;
```

统计覆盖模型空间 POINT 和 BLOCK 展开产生的 POINT。模式语义固定为：

| 环节 | POINT 行为 |
|---|---|
| Parser | 保存合法 POINT 并计入实体总数和类型统计 |
| Sketch | 不创建点对象；纯 POINT 输入返回无可转换实体 |
| FE | 创建独立节点，不创建 Truss |
| 原始日志 | TRACE 记录 POINT ID 和三维坐标 |
| Sketch 摘要 | 显示 POINT 数量并标注 Sketch ignored |
| FE 日志 | 显示 `points_processed`、节点数和 Truss 数 |

同步更新了 `docs/DxfData数据结构说明.md`。

### 2.4 FE 大坐标空间索引

FE 节点合并空间格坐标由 32 位 `int` 改为有界 `std::int64_t`：

- 缩放坐标在转换前检查有限性；
- 超过 64 位范围时钳制到保留边界；
- 邻域 `±1` 搜索不会发生有符号整数溢出；
- 节点距离判断和“距离小于等于容差即合并”语义保持不变。

该修改避免大坐标配极小合并容差时发生未定义整数转换。
