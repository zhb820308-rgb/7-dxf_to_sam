|FR\-06|日志和结果反馈|记录每个图元解析/转换/导入结果，展示结果摘要|

|编号|非功能需求|简要说明|

|NFR\-05|数据准确性<br>|相对位置/尺寸/连接关系与原图一致，拟合误差≤精度阈值|

### 1\.5 范围与约束

**支持处理：** 点、直线、圆、多段线、圆弧、样条曲线、椭圆/椭圆弧、倒角

**不支持：** 块（BLOCK）和外部依赖解析（需用户手动炸开）、螺旋线/圆环/修订曲线、图层解析、尺寸标注

**技术约束：**

- C\+\+开发，CMake构建，Qt做GUI，以插件形式在SAM中运行

- 通过SAM的skcGeomFactor

- y接口（CreatePoint/CreateLine/CreateCircle）绘制

- 使用OCC（OpenCASCADE）作为DXF解析库和曲线离散化库

- 目标格式：AutoCAD 2018版本DXF，坐标单位为毫米，世界坐标系

## 二、开发内容

我们把要做的内容分为了一个主引擎，五个子模块与一个交互界面 

### 2\.1 几何转换引擎

**对应需求：** BR\-02、FR\-03、FR\-05、FR\-06

- 接收`DxfData`，转换为`SamData`（点列表、直线列表、圆列表）

- 按优先级处理图元：点 → 直线 → 圆 → 圆弧/样条/椭圆 → 多段线 → 倒角

- 基点平移：将CAD图纸原点（0,0,0）平移到用户指定的基点位置，不改变图元间相对位置

- 倒角处理：解析并转换为SAM格式

- 单图元异常时跳过并记录，继续处理；不可恢复错误时终止并回滚

### 2\.2 DXF解析模块

**对应需求：** BR\-01、FR\-01、NFR\-02

- 封装`libdxfrw`库，读取DXF文件

- 解析图元：点（POINT）、直线（LINE）、圆（CIRCLE）、多段线（LWPOLYLINE）、圆弧（ARC）、样条曲线（SPLINE）、椭圆/椭圆弧（ELLIPSE）、倒角（CHAMFER）

- 输出`DxfData`数据结构（点列表、直线列表、圆列表、圆弧列表、样条列表、多段线列表、椭圆列表）

- 异常容错：

    - 文件不存在/权限不足/被占用 → 中断解析，弹窗提示

    - DXF格式损坏 → 中止解析，返回错误码

    - 零长度直线/零半径圆弧 → 跳过该图元，日志记录

    - 字段缺失 → 默认值替代，日志记录警告

    - 非AutoCAD 2018版本DXF → 弹窗提示兼容性风险，用户确认后继续

### 2\.3 曲线离散化模块（基于OCC）

**对应需求：** BR\-03、FR\-02、NFR\-05

- 基于OpenCASCADE几何建模内核实现曲线离散化

- 完整圆（360°闭合）：不离散化，直接调用SAM的CreateCircle接口

- 非完整圆弧：基于OCC的`GCPnts_QuasiUniformDeflection`，按角度步长（默认5°）采样为点列，再通过CreateLine逐段连接

- 样条曲线（Spline/NURBS）：调用OCC的`GCPnts_QuasiUniformDeflection`自适应离散化为多段线，默认容差0\.1mm

- 椭圆/椭圆弧：基于OCC的`Geom_Ellipse`类，通过参数方程采样离散化

- 离散化容差可配置（默认0\.1mm）

### 2\.4 SAM对接模块

**对应需求：** FR\-05、NFR\-02

- 对接SAM的`skcGeomFactory`接口：CreatePoint、CreateLine、CreateCircle

- 草图生命周期管理：每次导入使用新的独立草图，名称基于时间戳，不干扰已有内容

- 延迟刷新：所有图元创建完成后统一刷新场景

- 事务管理：可恢复错误跳过并继续；不可恢复错误终止导入，撤销本次已创建的全部对象

### 2\.5 统计模块

**对应需求：** BR\-04、FR\-04、NFR\-03

- 曲线统计：原始曲线图元数量

- 异常统计：被跳过的异常图元数量、类型和原因

- 质量指标：离散化的最大偏差

- 输出格式：界面直接展示 \+ 日志文件保存

### 2\.7 日志模块

**对应需求：** FR\-08、NFR\-02、NFR\-03

- 基于spdlog实现四级日志（DEBUG/INFO/WARNING/ERROR），颜色区分

- 控制台和日志文件双路输出

- 日志文件保存至SAM文件夹下的log文件夹，扩展名为\.log

- 超过50次自动清理，保留最近50次

- 崩溃时自动flush，确保最后一条日志不丢失

### 2\.7 GUI图形界面

**对应需求：** BR\-05、FR\-07、NFR\-01

- 文件选择：浏览并选择待导入的DXF文件

- 基点设置：输入X、Y、Z坐标值，或在SAM场景中拾取一个点

- 曲线拟合精度设置（如确认向用户开放）

- 启动导入按钮，进度条和状态反馈

- 统计报告展示：图元类型及数量、异常统计、最大偏差

- 错误弹窗提示

- 防止用户在必要参数缺失或文件校验未通过时执行导入

## 三、针对要做什么需要测试什么内容

### 3\.1 测试文件清单

|测试文件|内容特征|验证重点|
|---|---|---|
|`test_simple.dxf`|仅含直线和圆|解析→转换→SamData生成→绘制基本链路|
|`test_curves.dxf`|包含圆弧、样条曲线、倒角|OCC离散化结果及最大偏差是否小于预期值|
|`test_ship.dxf`|真实船舶图纸片段，混合图元|图元统计、转换完整性和整体可靠性|
|`test_malformed.dxf`|包含异常数据或缺失字段|可恢复图元能否跳过，不可恢复错误能否正确终止|
|`test_empty.dxf`|空文件|空数据处理和错误反馈|
|`test_version.dxf`|非AutoCAD 2018版本的DXF|兼容性风险识别及用户确认结果传递|
|`test_block.dxf`|包含块（BLOCK）|验证不支持图元的识别和提示|
|`test_large.dxf`|100MB以上大文件，大量图元|解析时间是否小于预期值、内存使用和处理稳定性|

### 3\.2 测试层次

|测试层次|测试工具/方式|覆盖内容|
|---|---|---|
|**单元测试**|GoogleTest|核心函数边界条件：零长度直线、零半径圆弧、极端坐标值、空数据、无效容差、字段缺失、离散点数不足|
|**集成测试**|上述DXF测试文件|解析→转换→离散化→SamData生成→统计→日志各模块协同工作|
|**端到端测试**|在SAM中执行完整导入流程|GUI操作、图元导入、SAM交互（创建/移动/删除无崩溃）、基点平移验证、异常恢复、场景刷新、日志检查|

## 七、总结

**需求理解**：四大类业务需求对应六大功能需求，核心是“解析→拟合→转换→创建”四条链路。

**开发内容**：三大模块并行开发——解析日志（张宏博）、曲线界面（张鑫哲）、转换对接（文俊飞）。

**测试准备**：已规划8类测试文件，覆盖基本链路、曲线精度、异常处理、性能、倒角等场景。

**编码节奏**：三个迭代推进——MVP打通链路→复杂曲线支持→产品化完善。
