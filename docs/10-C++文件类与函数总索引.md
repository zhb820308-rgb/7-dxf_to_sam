# VTKToolset C++ 文件、类与函数总索引（14 个 `.cpp` 版）

本文对应当前实际源码。`src/Example1` 有 12 对 `.h/.cpp`，
`src/Example1Toolset` 有 2 对 `.h/.cpp`，合计 14 个 `.cpp` 和 14 个 `.h`。

项目有两条明确分开的业务路线：

```text
DXF 文件
  ↓ DxfInputFile + DxfParser + DxfBlockExpansion
DxfData（公共 DXF 数据）
  ├─ SketchConversion → SamData → SketchImport → SAM Sketch
  └─ FeConversion     → FeData  → FeImport     → SAM Model / Part
```

## 一、14 对文件总览

| 文件 | 所属层 | 一句话作用 |
|---|---|---|
| `DxfData.h` / `DxfData.cpp` | Common Core | 公共 DXF 实体、请求、结果、默认值和校验 |
| `GeometryUtils.h` / `GeometryUtils.cpp` | Common Core | Sketch/FE 共用的曲线数学算法 |
| `DxfImportRuntime.h` / `DxfImportRuntime.cpp` | Common Core | 日志、导入会话和事务状态机 |
| `DxfInputFile.h` / `DxfInputFile.cpp` | Input | Unicode 路径和 libdxfrw 输入适配 |
| `DxfParser.h` / `DxfParser.cpp` | Parser | libdxfrw 回调、实体检查、坐标变换和解析入口 |
| `DxfBlockExpansion.h` / `DxfBlockExpansion.cpp` | Parser | BLOCK/INSERT 递归展开 |
| `SketchConversion.h` / `SketchConversion.cpp` | Sketch Core | `DxfData → SamData` 和 Sketch 纯事务顺序 |
| `SketchImport.h` / `SketchImport.cpp` | Sketch SDK | 把 `SamData` 写入 SAM Sketch |
| `FeConversion.h` / `FeConversion.cpp` | FE Core | `DxfData → FeData` 和 FE 纯事务顺序 |
| `FeImport.h` / `FeImport.cpp` | FE SDK | 把 `FeData` 写入 SAM Model/Part |
| `DxfImportApplication.h` / `DxfImportApplication.cpp` | Application | 公共用例编排、模式分流、提示和进度 |
| `Example1Module.h` / `Example1Module.cpp` | SAM/Python | 注册 `Example1.pyd` 及遗留教学 Fragment |
| `Example1Toolset.h` / `Example1Toolset.cpp` | Qt Toolset | 插件、菜单、参数窗口、图层选择 |
| `DxfLogViewerDialog.h` / `DxfLogViewerDialog.cpp` | Qt Toolset | DXF 日志查看器 |

## 二、公共 Core

### 1. `DxfData.h` 与 `DxfData.cpp`

这是全项目的公共“数据字典”。它不能包含 SAM SDK，也不包含 Sketch/FE 专属中间数据。

主要 DXF 类型：

| 类型 | 作用 |
|---|---|
| `DxfPoint3D` | 三维坐标值对象 |
| `DxfPoint` | DXF POINT |
| `DxfLine` | 起点、终点和实体 ID |
| `DxfCircle` | 圆心、半径和实体 ID |
| `DxfArc` | 圆心、半径、起止角 |
| `DxfLWPolyline` | 顶点、闭合状态和 bulge |
| `DxfEllipse` | 椭圆中心、长轴、比例和参数范围 |
| `DxfSpline` | 控制点、拟合点、节点和权重 |
| `InsertInfo` | BLOCK/INSERT 的平移、缩放、旋转和阵列参数 |
| `DxfBlock` | 块定义及块内实体 |
| `DxfEntityStats` | 输入、接受、拒绝、生成及分类数量 |

`DxfData` 主要函数：

- `addPoint()/addLine()/addCircle()/addArc()`：加入基本实体；
- `addLWPolyline()/addEllipse()/addSpline()`：加入复杂曲线；
- `addInsert()`：保存 INSERT 实例；
- `addBlock()`：保存块定义；
- `entityCount()`：统计实体总数；
- `entityStats()`：返回分类统计；
- `setError()/errorCode()/errorMessage()`：保存解析阶段错误；
- `clear()`：提前释放大图数据。

公共配置和校验：

| 类型/函数 | 作用 |
|---|---|
| `DxfImportDefaults` | 曲线公差、节点公差和输出档位 |
| `DxfImportMode` | `Sketch` 或 `FiniteElement` |
| `DxfImportRequest` | 一次导入的全部输入参数 |
| `parseIgnoredDxfLayers()` | 逗号文本转去重图层集合 |
| `DxfNumeric::*` | NaN、Inf、正数和范围检查 |
| `DxfImportValidation::validate()` | 校验基点、公差和输出上限 |
| `selectDxfImportMode()` | 解析模式并检查 FE 模型名/Part 名 |
| `validateDxfImportRequest()` | 组合数值与模式预检 |

公共结果类型：

- `DxfImportErrorCode`：稳定错误分类；
- `ImportBuildStatus/ImportBuildResult`：Builder 单步结果；
- `DxfImportBuildDetail::rollbackAfterFailure()`：Sketch/FE 共用的失败补偿模板，调用具体 Builder 的 `rollback()`，同时保留原错误与回滚结果；
- `DxfImportOutcomeStatus/DxfImportOutcome`：完整用例结果；
- `DxfImportOutcome::fromBuildFailure()`：把 Builder 失败转成对外结果。

### 2. `GeometryUtils.h` 与 `GeometryUtils.cpp`

只做数学计算，不读取文件、不显示窗口、不修改 SAM 数据库。

主要函数：

- `distance3D()`：三维距离；
- `nearlyEqual()`：按公差比较；
- `normalizedSweep()`：统一角度方向和范围；
- `segmentsForArc()`：根据半径、角度和弦高误差计算段数；
- `tessellateArc()`：圆弧离散为线段；
- `tessellateLWPolyline()`：处理直线段和 bulge 圆弧；
- `tessellateEllipse()`：椭圆离散；
- `tessellateSpline()`：使用 OCCT 构造并离散样条；
- `appendSegments()`：统一输出离散线段。

### 3. `DxfImportRuntime.h` 与 `DxfImportRuntime.cpp`

管理两条路线共用的运行环境，不包含 `SamData` 和 `FeData`。

日志函数：

- `createDxfImportLogger()`：创建单次导入日志；
- `dxfErrorLogger()`：获取公共错误日志；
- `dropDxfImportLogger()`：从 spdlog 注册表注销；
- `logRawDxfData()`：记录解析后的公共 DXF 实体；
- `reportImportError()`：记录结构化错误；
- `failImport()`：组合日志、警告和失败返回；
- `retainRecentImportLogs()`：只保留最近 50 个导入日志。

`DxfImportSession`：

- 构造函数生成 import ID、创建 logger、启动计时；
- `elapsed()` 返回累计耗时；
- `finish()` 刷新并注销日志；
- 析构函数作为 RAII 兜底自动收尾。

`ImportTransaction`：

- `begin()`：进入 Preparing；
- `markResourceOwned()`：标记已创建但未提交的 SAM 对象；
- `startWriting()`：进入 Writing；
- `startCommitting()/markCommitted()`：提交状态；
- `rollback()`：执行补偿清理；
- `state()/ownsResource()`：查询状态。

## 三、DXF 输入与解析

### 4. `DxfInputFile.h` 与 `DxfInputFile.cpp`

主要函数：

- `DxfInputFile::prepare()`：把 Qt 路径转换成 libdxfrw 可读取路径；
- `pathForReader()`：返回最终窄字符串路径；
- `errorMessage()`：返回路径适配失败原因；
- 析构函数：删除本次创建的临时文件。

它单独保留，是因为 Parser 和 Qt 图层扫描都需要它。

### 5. `DxfParser.h` 与 `DxfParser.cpp`

包含四组职责，但都属于“一次 libdxfrw 读取过程”。

`DxfParser`：

- `parseFile()`：检查参数、准备路径、调用 libdxfrw、展开块并检查最终结果。

`DxfReaderCallbacks`：

- `addPoint()/addLine()/addCircle()/addArc()`：接收基本实体回调；
- `addLWPolyline()/addEllipse()/addSpline()`：接收复杂曲线；
- `addInsert()`：接收块引用；
- `addBlock()/endBlock()`：切换块定义上下文；
- `isIgnoredLayer()`：执行图层过滤；
- `targetData()`：决定写入主图还是当前块。

实体检查函数：

- `isValidPoint()/isValidLine()/isValidCircle()`；
- `isValidArc()/isValidEllipse()/isValidSpline()`；
- 负责拒绝 NaN、Inf、负半径和不完整样条。

坐标变换：

- `DxfTransform::identity()`；
- `fromInsert()`：由 INSERT 构造变换；
- `applyPoint()/applyVector()`；
- `combine()`：组合父块和子块变换；
- `transformedScale()/determinant()`。

### 6. `DxfBlockExpansion.h` 与 `DxfBlockExpansion.cpp`

主要函数：

- `expandBlocks()`：主入口；
- `expandInsert()`：展开一个 INSERT；
- `expandBlock()`：递归展开块内容；
- `appendTransformed*()`：变换并追加各类实体；
- `reserveGeneratedEntities()`：执行累计输出预算；
- `wouldExceedLimit()`：防止整数溢出和超限；
- `blockKey()`：统一块名查找；
- `emitExpansionError()`：保存展开失败信息。

## 四、Sketch 路线

### 7. `SketchConversion.h` 与 `SketchConversion.cpp`

纯 C++ Sketch Core，不调用 SAM SDK。

`SamData`：

- `lines()/circles()`：转换结果；
- `curveSegments()`：离散线段与原曲线的映射；
- `setError()/clear()`：错误与清理。

`ConversionEngine`：

- `convert()`：`DxfData → SamData`；
- `translate()`：应用用户基点；
- 复杂曲线调用 `GeometryUtils` 离散；
- 超过输出预算时设置 `ConversionLimit`。

Sketch 事务接口：

- `ISamImportBuilder`：begin、createLines、createCircles、commit、rollback；
- `buildSamSketch()`：固定 begin → lines → circles → commit；
- `rollbackAfterFailure()`：失败后补偿回滚；
- `logConvertedSamData()`：记录 Sketch 专属转换结果。

### 8. `SketchImport.h` 与 `SketchImport.cpp`

SAM SDK 边界，负责 `SamData → SAM Sketch`。

`runSketchImport()`：

1. 调用 `ConversionEngine`；
2. 显示 Sketch 转换错误或预算提示；
3. 创建 `DxfImportProgress`；
4. 调用 `buildSamSketch()`；
5. 输出统计并返回 `DxfImportOutcome`。

`SamBuilder`：

- `beginImport()`：创建 Sketch 和几何工厂；
- `createLines()`：调用 SAM Sketch 线接口；
- `createCircles()`：调用 SAM 圆接口；
- `commit()`：提交、刷新场景和视图；
- `rollback()`：删除未完成 Sketch；
- `setProgressCallback()`：接入取消和进度；
- `sketchName()`：返回实际 Sketch 名。

## 五、FE 路线

### 9. `FeConversion.h` 与 `FeConversion.cpp`

纯 C++ FE Core，不调用 SAM SDK。

数据类型：

- `FeNode`：节点 ID 和坐标；
- `FeTruss`：单元 ID、起点节点和终点节点；
- `FeConversionStats`：合并、跳过和输出统计；
- `FeData`：节点、杆单元、空间哈希和错误状态。

`FeData` 主要函数：

- `getOrCreateNode()`：按公差复用节点；
- `addTruss()`：去重并添加杆单元；
- `findNearbyNode()`：查询相邻空间桶；
- `bucketKey()/neighborKeys()`：空间哈希；
- `clear()/setError()`。

`FeConversionEngine`：

- `convert()`：`DxfData → FeData`；
- `feedSegment()/feedSegments()`：把线段变成节点和杆；
- `setProgressCallback()`：进度和取消；
- POINT 生成独立节点；
- 曲线先经 `GeometryUtils` 离散，再生成 Truss。

FE 事务接口：

- `IFeImportBuilder`：begin、createNodes、createTrusses、commit、rollback；
- `buildFePart()`：固定 begin → nodes → trusses → commit。

### 10. `FeImport.h` 与 `FeImport.cpp`

SAM/Python 边界，负责 `FeData → SAM Model/Part`。

`runFiniteElementImport()`：

1. 调用 `FeConversionEngine`；
2. 处理取消、预算和转换错误；
3. 调用 `buildFePart()`；
4. 记录节点、杆和耗时；
5. 返回最终 Outcome。

`PythonFiniteElementBuilder`：

- `beginImport()`：获取或创建 Model 和 Part；
- `createNodes()`：批量执行 `createNode()`；
- `createTrusses()`：批量执行 `Element(TRUSS)`；
- `commit()`：显示 Part 并刷新视图；
- `rollback()`：删除失败导入创建的 Part；
- `runCommand()`：通过 SAM 内嵌 Python 执行命令；
- `escapePythonString()`：安全生成 Python 字符串字面量。

## 六、应用编排与模块注册

### 11. `DxfImportApplication.h` 与 `DxfImportApplication.cpp`

`runDxfImport()` 是公共主入口：

```text
校验请求
 → 解析 DXF
 → 记录原始实体
 → 根据 DxfImportMode 唯一分叉
    ├─ runSketchImport()
    └─ runFiniteElementImport()
```

辅助内容：

- `failedImport()/failedBuildImport()`：统一错误返回；
- `DxfImportFeedback::showBudgetError()`：输出预算提示；
- `DxfImportFormatting::*`：错误码、阶段名和摘要文字；
- `DxfImportProgress`：统一进度窗口、取消位置和幂等关闭。

### 12. `Example1Module.h` 与 `Example1Module.cpp`

当前模块入口：

- `Example1PytModule`：SAM/Python 门面；
- `importDxf()`：从 `omuArguments` 读取参数，构造请求并调用 `runDxfImport()`；
- `DefineMethods()/DefineConstants()`：注册 Python 可调用方法；
- `Example1Initialize()/Example1Finalize()`：引用计数初始化和清理；
- `initExample1()`：Windows/Python 扩展导出入口。

遗留教学代码：

- `SAMExample1Fragment`：旧矩形/线段示例；
- `kefKLine`：旧几何编辑器；
- 它们不属于当前 DXF 主链，但保留用于 SAM SDK 教学。

## 七、Qt Toolset

### 13. `Example1Toolset.h` 与 `Example1Toolset.cpp`

`Example1ToolsetPlugin`：

- `registerToolset()`：SAM 加载 DLL 后注册到 Part 模块；
- `Q_PLUGIN_METADATA/Q_INTERFACES`：Qt 插件元数据。

`Example1ToolsetGui`：

- `createMenuItems()`：创建导入和日志菜单；
- `onImportDxf()`：启动导入 Form；
- `onViewDxfLogs()`：打开日志查看器。

`Example1Form/Example1DB`：

- Form 连接 SAM 生命周期和 DXF 对话框；
- `getFirstDialog()` 返回 `Example1DXFImportDialog`；
- `Example1DB` 是保留的旧长宽教学对话框。

`Example1DXFImportDialog`：

- `onBrowse()`：选择文件并扫描图层；
- `onImportModeChanged()`：切换 Sketch/FE 输入项；
- `onDrawingSizeChanged()`：切换小图/大图参数；
- `onCmdOk()`：校验并发送 `Example1.importDxf` 命令。

`DxfLayerReader/MultiSelectComboBox`：

- `collectDxfLayers()`：读取、排序 DXF 图层；
- `setItems()/checkedItems()`：管理多选图层；
- `filterItems()/updateSummary()`：搜索和摘要显示。

### 14. `DxfLogViewerDialog.h` 与 `DxfLogViewerDialog.cpp`

- `refreshLogFiles()/loadSelectedLog()`：选择日志；
- `loadNextLogChunk()`：QTimer 分批加载；
- `detectLevel()/extractTimestamp()/extractMessage()`：解析日志；
- `acceptsLine()/matchesEntityFilter()`：过滤；
- `findOrCreateEntityItem()/addLogLine()`：构造日志树；
- `cancelLoading()/finishLoading()`：结束加载；
- 最多读取日志最近 8 MiB，避免界面卡死。

## 九、推荐阅读顺序

第一次只看调用链：

1. `Example1Toolset.cpp`；
2. `Example1Module.cpp`；
3. `DxfImportApplication.cpp`；
4. `DxfParser.cpp`；
5. 根据模式选择 `SketchConversion/SketchImport` 或 `FeConversion/FeImport`。

遇到陌生数据类型时查 `DxfData.h`，遇到曲线算法时查 `GeometryUtils.cpp`，
遇到日志和事务时查 `DxfImportRuntime.cpp`。
