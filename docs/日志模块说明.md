# 日志模块说明

## 概述

DXF 导入插件的日志模块从 `Example1PytModule.cpp` 中独立出来，由 `DxfImportLogger.h` / `DxfImportLogger.cpp` 两个文件组成，基于 [spdlog](https://github.com/gabime/spdlog) 库实现。

## 文件结构

| 文件                                   | 职责                                       |
| -------------------------------------- | ------------------------------------------ |
| `src/Example1/DxfImportLogger.h`     | 日志模块接口（7 个公开函数声明）           |
| `src/Example1/DxfImportLogger.cpp`   | 日志模块实现（约 250 行）                  |
| `src/Example1/Example1PytModule.cpp` | 调用方，`importDxf` 函数通过接口使用日志 |

## 依赖

- **spdlog**（v1.15.1）：日志底层库，通过 vcpkg 安装
- **fmt**：spdlog 的格式化依赖，由 vcpkg 自动安装
- **Qt5**：`QDateTime`、`QDebug`、`QDir`、`QFileInfo` 等（用于日志文件路径管理）

## 架构

### 两条日志通道

| 通道         | 创建函数                      | 日志文件路径                         | 记录级别     | 生命周期               |
| ------------ | ----------------------------- | ------------------------------------ | ------------ | ---------------------- |
| 每次导入日志 | `createDxfImportLogger(id)` | `logs/imports/dxf_import_<id>.log` | trace 及以上 | 一次`importDxf` 调用 |
| 全局错误日志 | `dxfErrorLogger()`          | `logs/dxf_import_errors.log`       | error only   | 进程运行期间           |

### 日志目录结构

```
<程序运行目录>/
  └── logs/
        ├── dxf_import_errors.log          ← 全局错误日志，10 MiB × 5 份轮转
        └── imports/
              ├── dxf_import_20260729_112233_456.log  ← 每次导入独立一份
              ├── dxf_import_20260729_140015_789.log
              └── ...（自动保留最近 50 份，超出自动删除）
```

> 日志根目录由 `QCoreApplication::applicationDirPath() + "/logs"` 决定。

## API 参考

### 7 个公开函数

#### 1. `createDxfImportLogger`

```cpp
std::shared_ptr<spdlog::logger> createDxfImportLogger(const std::string& importId);
```

创建每次导入专用的 logger 实例。

- **日志级别**：`spdlog::level::trace`（记录所有级别）
- **flush 策略**：warn 及以上自动刷新磁盘
- **格式**：`%Y-%m-%d %H:%M:%S.%e [%l] %v`
- **失败处理**：返回 `nullptr`，调用方检查并优雅降级

#### 2. `dxfErrorLogger`

```cpp
std::shared_ptr<spdlog::logger> dxfErrorLogger();
```

获取全局共享的错误 logger（单例，惰性初始化，线程安全）。

- **日志级别**：`spdlog::level::err`
- **flush 策略**：每条 error 日志立即刷盘
- **轮转**：单文件最大 10 MiB，保留最近 5 份
- **失败处理**：返回 `nullptr`

#### 3. `dropDxfImportLogger`

```cpp
void dropDxfImportLogger(const std::string& importId);
```

从 spdlog 全局注册表中移除指定导入的 logger。

**调用时机**：每次 `importDxf` 返回前必须调用（成功/失败均需清理），防止长时间运行后注册表内存泄漏。

#### 4. `logRawDxfData`

```cpp
void logRawDxfData(const std::shared_ptr<spdlog::logger>& logger,
    const std::string& importId, const DxfData& data);
```

以 trace 级别记录 **原始 DXF 解析结果**的全部图元数据。

记录的类型：

- `POINT` — id, position (x, y, z)
- `LINE` — id, start, end
- `CIRCLE` — id, center, radius
- `ARC` — id, center, radius, start_angle, end_angle, ccw
- `LWPOLYLINE` — id, 顶点数, closed, const_z + 每个顶点坐标 + 每个段 bulge
- `ELLIPSE` — id, center, major_axis, ratio, start_param, end_param, ccw

`logger` 为 `nullptr` 时无操作。

#### 5. `logConvertedSamData`

```cpp
void logConvertedSamData(const std::shared_ptr<spdlog::logger>& logger,
    const std::string& importId, const SamData& data);
```

以 trace 级别记录 **转换后的 SAM 数据**（已应用基点偏移）。

记录的类型：

- `POINT` — id, position
- `LINE` — id, start, end
- `CIRCLE` — id, center, radius

`logger` 为 `nullptr` 时无操作。

#### 6. `reportImportError`

```cpp
void reportImportError(
    const std::shared_ptr<spdlog::logger>& logger,
    const std::shared_ptr<spdlog::logger>& errorLogger,
    const std::string& importId,
    const std::string& pathText,
    const std::string& stage,
    const std::string& detail,
    long long elapsedMs);
```

统一的错误报告函数，**替代重复的 `if(logger)/if(errorLogger)` 模式**。

- `stage`：标识失败阶段（`"parse"` / `"conversion"` / `"begin_import"` / `"commit"`）
- `detail`：附加上下文（如 ` error="xxx"` 或 ` sketch="x" submitted=5 error="y"`）
- `elapsedMs`：从 `totalTimer` 获取的总耗时

同时向 `logger`（单次导入日志）和 `errorLogger`（全局错误日志）写入。

## 输出日志结构

日志模块的所有输出遵循统一的格式规范，由 **时间戳**、**级别标记**、**导入标识**、**消息类型** 和 **键值对数据** 五部分组成。

### 日志行格式

```
时间戳 [级别] [import=导入ID] 消息类型 键=值 键=值 ...
```

| 组成部分     | 格式 / 示例                                    | 说明                                                                 |
| ------------ | ---------------------------------------------- | -------------------------------------------------------------------- |
| **时间戳**   | `2026-07-29 11:22:33.456`                      | spdlog pattern: `%Y-%m-%d %H:%M:%S.%e`，精确到毫秒                   |
| **级别标记** | `[trace]` `[info]` `[warn]` `[error]`        | 方括号包裹，小写英文                                                 |
| **导入标识** | `[import=20260729_112233_456]`                 | 格式 `yyyyMMdd_HHmmss_zzz`，在整个导入生命周期内唯一，关联同一次导入 |
| **消息类型** | `started` `parse_completed` `raw LINE` 等     | 固定的小写英文标识，便于 `grep` 过滤和脚本解析                       |
| **键值数据** | `file="C:\drawing.dxf"` `points=10` 等       | `key=value` 形式，字符串值用双引号包裹，数值直接写出                  |

### 导入标识（importId）生成规则

```
importId = QDateTime::currentDateTime().toString("yyyyMMdd_HHmmss_zzz")
```

- `yyyy` — 四位年份
- `MM` — 两位月份（01–12）
- `dd` — 两位日期（01–31）
- `HH` — 两位小时（00–23）
- `mm` — 两位分钟（00–59）
- `ss` — 两位秒（00–59）
- `zzz` — 三位毫秒（000–999）

> 若同一毫秒内产生两个同名日志文件（极端并发），`createDxfImportLogger` 会自动追加 `_1`、`_2` 等后缀避免冲突。

### 消息分类

日志输出按**语义层级**划分为三大类：

#### 1. 阶段事件（info 级别）

标记导入生命周期的六个关键阶段节点，每个节点携带统计摘要：

| 消息类型               | 携带的键值对                                                                                | 含义                   |
| ---------------------- | ------------------------------------------------------------------------------------------- | ---------------------- |
| `started`              | `file`（DXF 文件路径）, `base`（基点坐标 `(x, y, z)` 格式）                                | 导入开始               |
| `parse_completed`      | `points` `lines` `circles` `arcs` `lw_polylines` `ellipses` `duration_ms`               | DXF 解析阶段成功完成   |
| `conversion_completed` | `points` `lines` `circles` `duration_ms`                                                  | 坐标转换阶段成功完成   |
| `succeeded`            | `sketch`（草图名称）, `submitted`（提交图元总数）, `build_duration_ms` `total_duration_ms` | 全部三个阶段成功完成   |
| `{stage}_failed`       | `file`（仅全局错误日志）, `error`（错误描述）, `sketch`（如有）, `submitted`（如有）, `elapsed_ms` | 某阶段失败（见下方详述） |

**阶段事件示例**：

```
2026-07-29 11:22:33.456 [info] [import=20260729_112233_456] started file="C:\drawing.dxf" base=(100.0, 200.0, 0.0)
2026-07-29 11:22:33.470 [info] [import=20260729_112233_456] parse_completed points=10 lines=50 circles=5 arcs=3 lw_polylines=2 ellipses=0 duration_ms=14
2026-07-29 11:22:33.510 [info] [import=20260729_112233_456] succeeded sketch="Sketch_1" submitted=65 build_duration_ms=25 total_duration_ms=54
```

#### 2. 图元数据（trace 级别）

以 `trace` 级别逐条记录每个图元的详细几何参数，分为 **raw**（原始 DXF 解析结果）和 **converted**（坐标转换后）两组：

**raw 图元（`logRawDxfData` 输出）**：

| 消息类型            | 键值对                                                                                                       |
| ------------------- | ------------------------------------------------------------------------------------------------------------ |
| `raw POINT`         | `id` `position=(x, y, z)`                                                                                 |
| `raw LINE`          | `id` `start=(x, y, z)` `end=(x, y, z)`                                                                   |
| `raw CIRCLE`        | `id` `center=(x, y, z)` `radius`                                                                          |
| `raw ARC`           | `id` `center=(x, y, z)` `radius` `start_angle` `end_angle` `ccw`                                      |
| `raw LWPOLYLINE`    | `id` `vertices` `closed` `const_z`                                                                        |
| `raw … VERTEX`      | （跟随在 LWPOLYLINE 之后）`id` `index` `position=(x, y, z)`                                             |
| `raw … SEGMENT`     | （跟随在 LWPOLYLINE 之后）`id` `index` `start_vertex` `end_vertex` `bulge`                          |
| `raw ELLIPSE`       | `id` `center=(x, y, z)` `major_axis=(x, y, z)` `ratio` `start_param` `end_param` `ccw`                |

**converted 图元（`logConvertedSamData` 输出）**：

| 消息类型              | 键值对                                                      |
| --------------------- | ----------------------------------------------------------- |
| `converted POINT`     | `id` `position=(x, y, z)`                                 |
| `converted LINE`      | `id` `start=(x, y, z)` `end=(x, y, z)`                   |
| `converted CIRCLE`    | `id` `center=(x, y, z)` `radius`                          |

> **注意**：raw 阶段的 ARC / LWPOLYLINE / ELLIPSE 在转换阶段会被离散化为 LINE 段，因此 converted 日志中只有 POINT / LINE / CIRCLE 三种类型。

**图元数据示例**：

```
2026-07-29 11:22:33.471 [trace] [import=20260729_112233_456] raw LINE id=1 start=(0.0, 0.0, 0.0) end=(10.0, 20.0, 0.0)
2026-07-29 11:22:33.471 [trace] [import=20260729_112233_456] raw LWPOLYLINE id=5 vertices=4 closed=1 const_z=0.0
2026-07-29 11:22:33.472 [trace] [import=20260729_112233_456] raw LWPOLYLINE id=5 VERTEX index=0 position=(0.0, 0.0, 0.0)
2026-07-29 11:22:33.473 [trace] [import=20260729_112233_456] raw LWPOLYLINE id=5 SEGMENT index=0 start_vertex=0 end_vertex=1 bulge=0.5
2026-07-29 11:22:33.486 [trace] [import=20260729_112233_456] converted LINE id=1 start=(100.0, 200.0, 0.0) end=(110.0, 220.0, 0.0)
```

#### 3. 错误事件（error 级别）

由 `reportImportError()` 统一生成，**同时写入两条通道**，但内容略有差异：

| 通道               | 格式                                                                                     | 特点             |
| ------------------ | ---------------------------------------------------------------------------------------- | ---------------- |
| 每次导入日志       | `[import={id}] {stage}_failed{detail} elapsed_ms={n}`                                  | 不含 `file` 字段 |
| 全局错误日志       | `[import={id}] {stage}_failed file="{path}"{detail} elapsed_ms={n}`                     | 含 `file` 字段   |

**stage 取值**：

| stage            | 含义             | 典型 detail 内容                                  |
| ---------------- | ---------------- | ------------------------------------------------- |
| `parse`          | DXF 解析失败     | ` error="Unknown entity type"`                  |
| `conversion`     | 坐标转换失败     | ` error="null geometry"`                        |
| `begin_import`   | SAM 导入初始化失败 | ` error="sketch not found"`                   |
| `commit`         | SAM 提交失败     | ` sketch="S1" submitted=500 error="OOM"` |

> `detail` 参数随 `stage` 不同而变化，`begin_import` 不含 `sketch`/`submitted`，`commit` 则包含。

**错误事件示例**：

```
# 每次导入日志中：
2026-07-29 11:22:33.480 [error] [import=20260729_112233_456] parse_failed error="Unknown entity type" elapsed_ms=5

# 全局错误日志中（多了 file 字段）：
2026-07-29 11:22:33.480 [error] [import=20260729_112233_456] parse_failed file="C:\broken.dxf" error="Unknown entity type" elapsed_ms=5
```

### 坐标格式约定

所有几何坐标使用统一的 `(x, y, z)` 元组格式：

```
(100.0, 200.0, 0.0)
(-50.5, 300.25, 15.0)
```

- 三个浮点数，用逗号 + 空格分隔
- 括号包裹，无额外空白
- 小数部分为 0 时保留 `.0`（C++ 默认流输出行为）

### 日志解析建议

日志格式设计兼顾**人工可读**和**脚本可解析**：

- **按导入过滤**：`grep "import=20260729_112233_456" dxf_import_*.log`
- **按级别过滤**：`grep "\[error\]" dxf_import_errors.log`
- **按消息类型过滤**：`grep "parse_completed" logs/imports/*.log`
- **提取特定字段**：键值对格式可直接用正则 `(\w+)=("[^"]*"|\S+)` 提取所有字段

## `importDxf` 调用流程

```
① 生成 importId = yyyyMMdd_HHmmss_zzz
② logger      = createDxfImportLogger(importId)
   errorLogger = dxfErrorLogger()
   totalTimer 启动

③ [info] "started" —— 记录文件路径和基点

④ —— 阶段 1：解析 ——
   stageTimer 启动
   DxfParser.parseFile()
   ├─ 成功 → [info] "parse_completed" + logRawDxfData()   (trace)
   └─ 失败 → reportImportError("parse") + dropDxfImportLogger() + 返回

⑤ —— 阶段 2：转换 ——
   stageTimer 重启
   ConversionEngine.convert()
   ├─ 成功 → [info] "conversion_completed" + logConvertedSamData() (trace)
   └─ 失败 → reportImportError("conversion") + dropDxfImportLogger() + 返回

⑥ —— 阶段 3：SAM 对接 ——
   stageTimer 重启
   SamBuilder.beginImport()
   └─ 失败 → reportImportError("begin_import") + dropDxfImportLogger() + 返回

   builder.createPoints/Lines/Circles()

   builder.commit()
   ├─ 失败 → reportImportError("commit") + dropDxfImportLogger() + rollback + 返回
   └─ 成功 → [info] "succeeded" + logger->flush()

⑦ dropDxfImportLogger(importId) —— 清理
```

## 关键改进点

| 改进                      | 说明                                                                               |
| ------------------------- | ---------------------------------------------------------------------------------- |
| **模块独立**        | 6 个函数 + ~250 行从`Example1PytModule.cpp` 提取到 `DxfImportLogger.cpp`       |
| **消除重复**        | 5 处相同的错误日志`if/else` 模式替换为统一的 `reportImportError()` 调用        |
| **内存泄漏修复**    | 每次导入后调用`dropDxfImportLogger()` 清理 spdlog 注册表，防止长期运行后内存增长 |
| **Lines 日志补全**  | `logConvertedSamData` 添加了此前缺失的 Lines 图元日志记录                        |
| **stageTimer 修正** | 移除冗余的`stageTimer.start()`，改为就近声明并初始化                             |
