## 5. 构建系统发现

### 5.1 默认生成器不适用于当前环境

直接执行：

```powershell
cmake -S . -B build_stage4
```

处置：阶段四期间必须显式指定：

```text

```

### 5.2 测试默认关闭

`EXAMPLE1_BUILD_TESTS` 默认值为 `OFF`。仅生成生产目标时，随后运行 CTest 会得到 `No tests were found`。

处置：验收构建必须显式指定：

```text

```

此问题列入 P4-5 构建系统整理。在 P4-5 之前不改变默认值，避免将构建行为变化混入 P4-0。

### 5.3 GoogleTest 离线来源

测试使用 `FetchContent`。当前受限网络环境应显式复用现有本地源码：

```text
-DFETCHCONTENT_SOURCE_DIR_GOOGLETEST=D:/shixiSoftware/Homework/7-dxf_to_sam/build/_deps/googletest-src
```

P4-5 应评估将离线构建方式写入正式构建说明，但不得把开发机绝对路径写死到生产 CMake。
