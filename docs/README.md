# 项目文档

本目录只维护当前实现。阶段计划、逐批实施报告、旧合并说明和过期审查报告由 Git 历史保存，不再作为现行文档。

## 推荐阅读顺序

1. [初学者代码导读](09-初学者代码导读.md)：C++/Qt/大型项目经验较少时，先建立完整地图。
2. [C++ 文件、类与函数总索引](10-C++文件类与函数总索引.md)：逐文件查询职责和符号。
3. [系统架构](01-系统架构.md)：理解两个产品入口和模块边界。
4. [DXF 解析与转换流程](02-DXF解析与转换流程.md)：理解核心几何数据流。
5. [SAM 插件与 FE 导入](03-SAM插件与FE导入.md)：理解 SAM 侧调用、事务和 GUI。
6. [Web 编辑器与图形 Agent](04-Web编辑器与图形Agent.md)：理解 Web 侧运行方式和安全模型。
7. [构建部署与测试](05-构建部署与测试.md)：搭建环境并验证。
8. [安全限制与故障排查](06-安全限制与故障排查.md)：处理超限、失败和部署问题。
9. [当前状态与主要变更](07-当前状态与主要变更.md)：查看已完成能力和已知边界。
10. [样例与测试数据](08-样例与测试数据.md)：选择合适的 DXF 测试输入。

## 文档维护规则

- 源码、测试和 CMake 是行为事实来源；文档与代码冲突时应修正文档。
- 功能说明写当前行为，不按开发阶段追加新报告。
- 重要行为变化更新对应主题文档和“当前状态与主要变更”。
- 测试样例通过文件内容 SHA-256 识别，不只按文件名判断。
- 外部 SAM 资料仅作参考，不能代替当前源码和验收结果。
