# DXF Studio 网页端说明

## 1. 项目简介

`page` 是一个不依赖后端和第三方库的 DXF 点线离散编辑器。用户可以在浏览器中导入 ASCII DXF，将曲线按弦高公差离散为点和直线，在画布中查看、编辑、变换并重新导出 DXF。

普通编辑均在浏览器本地处理。只有主动运行 AI Agent 时，点线数据才会发送到本地 Agent 服务，并由服务按需调用配置的 AI API。

## 2. 文件结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构和操作入口 |
| `styles.css` | 工作区、侧栏、工具栏及响应式样式 |
| `dxf.js` | ASCII DXF 解析、几何离散化和 DXF 导出 |
| `app.js` | 页面状态、Canvas 绘制、交互编辑和文件操作 |
| `../server.js` | 静态页面服务和 AI 图形 Agent API |

## 3. 运行方式

不使用 AI 时可以直接双击 `index.html`。使用 AI Agent 时必须在项目根目录启动 Node.js 服务：

```powershell
node server.js
```

然后访问：

```text
http://127.0.0.1:8080
```

在页面的 AI 图形 Agent 面板中选择协议，并输入模型、API 地址和 API Key。

若页面由 VS Code Live Server（通常为 5500 端口）打开，仍需同时运行 `node server.js`；前端会自动尝试 8080 和 18080 端口的 Agent API。8080 无权使用或已被占用时，服务端会自动切换到 18080。

## 4. 已实现功能

### AI 图形 Agent

- 支持 OpenAI Responses、OpenAI 兼容 Chat Completions 和 Anthropic Messages 三种 Agent 协议。
- 可在页面输入提供商协议、模型、API 地址和 API Key。
- 运行 Agent 时会将协议、模型、API 地址和 API Key 保存到当前浏览器的 `localStorage`，下次打开页面自动恢复；可使用“清除缓存”移除。
- 支持自然语言驱动的分页检查、精确实体 ID 定位、测量、平移、旋转、缩放、复制、改图层、清理、删除以及添加点线。
- Agent 可确定性查找原生 `DIMENSION` 和 `LEADER` 标注线；炸开为普通线的标注仅按标注图层作为带置信度的候选。
- Agent 使用受约束的结构化工具调用操作图形副本，不执行任意脚本。
- 导入时保存独立的原图基线；Agent 只处理和修改工作副本，点击“应用到工作副本”也不会改变原图基线。
- 可点击“恢复原图”丢弃当前工作副本修改；AI 版本导出为新的 `_ai_revision.dxf` 文件，不覆盖导入文件。
- Agent 修改可通过 `Ctrl+Z` 撤销。
- 详细接口参见 [`../docs/AI图形Agent接口.md`](../docs/AI图形Agent接口.md)。

### DXF 导入与离散化

- 支持点击选择或拖放 `.dxf` 文件。
- 文件大小上限为 50 MB。
- 支持解析和显示以下 ASCII DXF 图元：
  - `POINT`
  - `LINE`
  - `CIRCLE`
  - `ARC`
  - `ELLIPSE`
  - `LWPOLYLINE`
  - `POLYLINE`
  - `SPLINE`（控制点及拟合点数据）
  - `INSERT`（包含普通块、嵌套块、行列阵列）
  - `DIMENSION`（展开关联标注块并保留确定的标注身份）
  - `LEADER`（保留引线身份）
- 支持多段线 bulge 圆弧。
- 圆弧离散的单段角度不超过 45°，并根据弦高公差继续细分。
- 支持图层名称、图层颜色和图层可见性。
- 块引用会组合应用块基点、插入点、旋转、缩放及父级嵌套变换。
- 页面会显示离散后的点数、直线数及原始图元数。

### 画布浏览

- 鼠标滚轮缩放。
- 空格拖动、鼠标中键拖动或平移工具移动画布。
- “适合画布”自动显示全部可见图元。
- 可切换背景网格。
- 实时显示鼠标对应的世界坐标。
- 可按图元类型或图层显示、隐藏几何。
- 点击图层行可高亮该图层的全部点和直线，同时淡化其他图层；再次点击取消高亮。

### 图元编辑

- 选择点或直线后，可在右侧属性面板直接修改坐标。
- 使用选择工具从画布空白处拖动可进行框选，与选择框相交的可见点和直线会被批量选中。
- 按住 `Shift` 点击图元可追加选择或取消选择；按住 `Shift` 从空白处框选可追加框选结果。
- 选中多个图元后，拖动其中任意一个已选图元可整体移动所有选中图元，并保持相对位置不变。
- 框选结果支持使用 `Delete` / `Backspace` 批量删除，并可通过 `Ctrl+Z` 撤销。
- 使用选择工具拖动直线端点，可以直接调整起点或终点。
- 使用选择工具拖动直线线身，可以整体移动该直线。
- 点图元也可以直接使用鼠标拖动。
- 可添加点和直线。
- 可删除选中图元。
- 支持整体平移、旋转和缩放。
- 支持最多 50 步撤销和 50 步重做；新编辑会清空重做分支。
- 修改弦高公差后，可以从原始 DXF 重新构建全部图元；处理不受图层或图元显示状态影响。
- `ARC`、`CIRCLE`、`ELLIPSE`、`SPLINE` 和多段线 bulge 弧段按新公差重新采样。
- `POINT`、`LINE` 和多段线直线段也会从原始数据重新生成，但弦高公差不会改变直线的段数。

### DXF 导出

- 导出内容为 ASCII DXF R2000（`AC1015`）。
- 编辑结果以 `POINT` 和 `LINE` 图元写入。
- 保留离散结果中的图层名称。
- 默认文件名为“原文件名_discretized.dxf”。

## 6. 使用流程

1. 点击“导入 DXF”，或把文件拖入画布。
2. 在右侧输入弦高公差，点击“重新离散化”。
3. 使用滚轮和平移工具检查几何。
4. 使用选择、点、直线工具进行编辑。
5. 如有需要，设置整体平移、旋转和缩放参数并应用。
6. 点击“导出 DXF”下载编辑后的点线模型。

## 7. 验证情况

已完成以下检查：

- `dxf.js` 和 `app.js` 通过 Node.js 语法检查。
- 使用 `example` 目录中的 24 个 ASCII DXF 样例进行批量解析。
- 覆盖直线、圆、圆弧、椭圆、多段线、NURBS 样条、拟合点样条和块引用。
- 使用“解析 → 离散 → 导出 → 再解析”流程验证点线 DXF 回读结果。

## 8. 当前边界

- 仅解析 ASCII DXF，不解析二进制 DXF，也不直接解析 DWG。
- `TEXT`、`MTEXT`、`DIMENSION`、`HATCH`、`SOLID` 等非点线几何不会导出。
- 只有拟合点、没有控制点的 `SPLINE` 会按拟合点折线连接；包含控制点和节点矢量的样条使用 NURBS 求值。
- 导出结果是离散后的点和直线，不会恢复为原始圆、圆弧、椭圆或样条类型。
- 块引用会在离散时展开，导出后不再保留块定义结构。
